# スーパー蒼き狼と白き牝鹿・元朝秘史（SFC）ROM 格式

KOEI，1993，SFC。ROM 1.5 MB（`0x180000`），HiROM，無 copier header。本文的「偏移」都是檔案偏移；CPU 位址 `$Cx:yyyy` 對應檔案偏移 `0x(x)yyyy`（`addr & 0x3FFFFF`）。程式是編譯過的 C（65816），常見的呼叫慣例是參數全部 push 到堆疊、用 `JSL` 呼叫；系統服務走 `JSL $C0:8000／$C0:8003`，前面 `PEA` 服務號（`0x4C` = LZ 解壓、`0x0B` = 上傳 VRAM 等）。

FC 版（`~/works/famicom-re/genchou/`）已經完整解析；SFC 版大部分表格的內容和 FC 版相同或只多了指標欄位，欄位意義沿用 FC 文件並在本作重新驗證（見 README 的驗證表）。

標記：**已驗證**＝有 Mesen 跑遊戲本身程式的獨立比對；**推測**＝只靠資料規律或 FC 版類比。

## 1. 壓縮

- 解壓程式 `$C0:9DB4`，就是共用的 `tools/koei_lz.py`（表在 `0x9C57`）。
- 「載入 LZ 第 n 筆」`$C6:7EC9`：指標表 `$C8:A9DA`（`0x8A9DA`），352 個 3-byte 指標，預設解到 `$7F:6000`。`Rom.entry(n)`。
- 重要的 LZ 項目：

| 項目 | 大小 | 內容 |
|------|------|------|
| 3 | 17664 | モンゴル編大地圖（23 × 24 tile，4bpp） |
| 4 | 17664 | 世界編大地圖 |
| 38–134 | 960 × 97 | 專屬頭像（0–56 男、57–96 女） |
| 135 | 7936 | 戰場用部隊等 sprite（未細看） |
| 136–182 | 868 × 47 | 戰場地圖記錄 |
| 229–233 | 3840–3968 | 戰場 tile 組 0–4 |

## 2. 文字與字型

- 單 byte：半形假名（`ESC H` = 平假名，預設；`ESC K` = 片假名）與 ASCII。數字、英文字母也是半形。
- 雙 byte：`0x8140 + g` 代表字型第 g 個字（g = 0–2045，到 `0x893D`）。字型 16 × 16 1bpp，每字 32 bytes，四個 8 × 8 依序左上、右上、左下、右下；g < `0x400` 在 `32 g`（bank `$C0`），其餘在 `0x130000 + 32 g`（bank `$D3`）。描字程式在 `$C7:5C79` 附近（碼 > `0x893D` 時：≥ `0x9140` 重新對應，其餘畫空白）。
- 字表 `data/charset.txt`：JIS X 0208 順序的子集（7 個符號、第一水準、第二水準），2036–2044 是另外附加的人名用字。對照方法：先拿項劉記與三國志III 的字型逐字比對（1539 字完全相同），其餘依 JIS 順序做序列對齊，最後人工看字形修正（例：間／閑、絃、后、唱 妾 娼 宵、槍、帖、槌 佃 柘 椿、募 墓 慕 暮）。2042「熹」字形接近但不完全確定，2045 是「〓」。人名、王家名、地名用到的 152 個漢字已逐一對照字形確認。

### 3.3 王家（區塊 A `+0x1185`，33 格 × 24 bytes）

| 偏移 | 內容 |
|------|------|
| 0–15 | 名稱（第 16 byte 為 0） |
| 17–19 | 第一個國（WRAM 3-byte 指標，`$7E:430A` + 50 × 國） |
| 20–22 | 國王（WRAM 3-byte 指標，`$7E:37F8` + 26 × 人物格） |
| 23 | 推測為文化（同人物 +22 的編號） |

名稱為空的格沒有使用。各劇本的國王指標都指向身分 3、王家欄等於該王家的人。

### 3.4 女性（區塊 B `+0`，最多 32 格 × 21 bytes）

`[姓名 15][FF][?][?][所在國][頭像碼 LE16]`，姓名第一 byte 為 0 時結束。頭像碼 bit 15 清除時是女性專屬頭像（LZ 38 + 57 + 碼），否則是組合臉。+16、+17 未解。

區塊 B 在女性表之後還有其他資料（`+0x2B5` 起是劇本 4 續行時會複製的部分，其中有開始年），未解。

## 5. 頭像

40 × 48 = 5 × 6 個 4bpp tile（列優先，960 bytes）。人物頭像程式 `$C4:5EDB(位置, 碼, …)`、女性 `$C4:5F63`：碼的 bit 15 清除且 < `0x60` 時是專屬頭像（`$C4:5E31`），否則組合臉（`$C4:5CEC` → `$C4:5812`）。

### 5.1 專屬頭像

LZ 項目 38 + n（n = 0–96）。人物用 n = 碼（0–56），女性 n = 57 + 碼。調色盤用 CGRAM 3（ROM 副本 `0x140D7`）。

### 5.2 組合臉

- 碼：bit 12–14 = 臉組 g，bit 9–11 = 組內頭型 m（取 mod 7），頭 H = 7g + m（56 個）。bit 6、5、4、8、7 依序選擇眼、鼻、口、上部、下部的第 2 個版本。其餘 bits 不用。
- 頭的圖：未壓縮，H < 28 在 `0x140000 + 0x780 H`，否則 `0x150000 + 0x780 (H − 28)`；每頭 60 tile（5 部位 × 2 版本）。
- 版面表（每頭一個 layout 編號 `0x4DBED + 2H`，共 22 種）：`0x4DC5D` 部位大小、`0x4DD39` 部位原點（欄 × 10 + 列）、`0x4DE15` 上部的區塊串（數量 + 每段「欄 列 寬 列數」4 位數）、`0x4DEC5` 下部的區塊串、`0x4DFAD` 部位在頭圖內的第一個 tile。56 個頭的 5 個部位剛好不重疊地蓋滿 30 格。
- 調色盤：臉組 4–6 用 CGRAM 2（`0x140B7`），其他用 CGRAM 3（`0x140D7`）。
- 臉組與文化的對應（推測，從人物 +22 的文化交叉比對）：0 モンゴル、1 中国、2 内アジア、3 インド、4 日本、5 西欧、6 東欧、7 イスラム。和人物 +22 的文化編號順序不同。

`verify_faces.py` 已驗證全部 97 張專屬頭像與資料中出現的 234 種組合臉碼（男 201、女 33）：VRAM tile、BG tilemap 的調色盤號、CGRAM 調色盤都一致。

## 6. 大地圖

- 一張 184 × 192 的圖：23 × 24 個 4bpp tile 列優先，LZ 3（モンゴル編，劇本 1）／LZ 4（世界，劇本 2–4）。
- 主畫面 BG2（mode 1，tilemap `$7800`，字元 `$2000`）：tile `0x70 + 23 列 + 欄`，放在欄 7–29、列 3–26，調色盤 6。
- 調色盤區塊 `$C8:ADFA`（`0x8ADFA`）：第 p 個 16 色調色盤在 `0x8ADFA + 32 p`。大地圖用 p = `0x35`（モンゴル，`0x8B49A`）、`0x39`（世界，`0x8B51A`）；後面幾個只差 1–2 色，推測是水面動畫。
- 顏色 15 是各地域內部：遊戲依王家用不同顏色／花紋填色（填色規則與資料未解）。
- 地名標籤位置：§3 的 `REGION_POS`（像素座標）。

已驗證（`verify_map.py`）：4 個劇本主畫面 VRAM 的 552 tile 在顏色 15 以外逐 pixel 相同、tilemap 552/552、CGRAM 調色盤 6 一致。

## 7. 戰場地圖

- 47 筆，每筆 868 bytes，LZ 136 + n：n = 0–13 是モンゴル編 14 地域，14–46 是世界 33 國（`$C7:92EB`：國編號，`$7E:5425` ≠ 0 時 + 14）。**和 FC 版的戰場記錄逐 byte 相同（47/47）**，格式見 FC 文件 §6：
  - `+0`：28 × 21 個值 v（列優先）
  - `+0x24C`：出入口格 14 × 10，值 = 相鄰國編號，`0x30` = 不是出入口
  - `+0x2D8`：地形 14 × 10：0 平地、1 城、2 街、3 砂漠、4 森林、5 山岳、6 河川、7 湖・海（意義沿用 FC 版的驗證）
- 畫法（SFC）：BG2 tilemap 在 tile (2, 3) 起放 28 × 21 格，值 v → tile `0x40 + v`、調色盤 6。tile 組 k 的圖是 LZ 229 + k（`$C7:9400`：`0xE5 + k`），tile v 在 `32 v`；調色盤是區塊 `$C8:ADFA` 的第 `0x20 + 2k` 個（`$C7:9518`；下一個只差顏色 13–14，兩者交替，推測是水面動畫）。
- tile 組：モンゴル編一律 0；世界編查 `0x7D807`（33 bytes，國 → 0–4）。使用數：0 = 20 張、1 = 6、2 = 5、3 = 6、4 = 10。

已驗證（`verify_battle_maps.py`）：把三個載入程式讀國編號的指令改成常數，47 張圖的 tilemap、tile、調色盤都和解碼一致。

## 8. 操作序列（驗證腳本用）

每個 `a:10` 是按住 10 幀；`wN` 是等 N 幀；序列從第 10 幀開始。

| 目的 | 按鍵 |
|------|------|
| 標題 → 劇本選單 | `w2100 start:30 w100 start:4 w300 a:10 w200 a:10 w200`（新しくゲームを始める） |
| 選劇本 | 劇本 2、3：`down` 1、2 次；劇本 4 不在選單，把 `$C4:2B4F` 改成 `LDA #$0003; NOP; NOP` |
| 劇本 1 到第一回合 | 選單後 `a:10 w200` × 6，再 `a:10 w300` × 4（1 人、モンゴル族、Yes、他國戰爭 Yes、戰鬥 Yes、すべて Yes、開場事件） |
| 主選單 | 2 × 4：方針 内政／指示 外交／人事 商人／軍事 情報 |
| 人事 | `down down a`；子選單（2 欄）：左上 屬國領主任命、右上 將軍（子息）、左中 政治顧問、右中 姫の嫁ぎ先、左下 將軍の人事（登用）、右下 后妃 |
| 政治顧問確認卡（人物欄位、男頭像） | 人事 → `down:10 w40` → `a` × 4（Yes、オノン河流域、カサル）→ 卡片（WRAM 家族格 0 `$7E:4C94`） |
| 后妃夜晚畫面（女頭像） | 人事 → `down down right` → `a` × 4（Yes、ボルテ、說明）→ 畫面（女性 0 `$7E:4F38`） |
| 遠征（戰場） | 軍事（`down` × 3、`a`）→ Yes → 地圖游標 `down:4 down:4 left:4`（ゴルゴナク河原）→ 総指揮 Yes → 編成 No → 預設值… → `遠征を開始してよろしいですか` → 戰場 |

畫面文字：半形字元在 BG3（tilemap `$7C00`），數字 d = tile `0x2C + 2d`、等級 A–E = `0x40 + 2k`，每字上下兩格。

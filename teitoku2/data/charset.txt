# Teitoku no Ketsudan II font glyph -> character, 32 glyphs per line; glyph g is text code 0x8140 + g (1216 glyphs,
# 16x16 1bpp at file 0x2B0000 + 32 g, the same tile order as Teitoku no Ketsudan). Glyph 0 is code 0x8140, the
# Shift-JIS full-width space (its font slot is not blank, see docs/ROM_FORMAT.md). Glyphs 1-22 are symbols, digits,
# letters and katakana, 23-1191 a JIS X 0208 level-1 kanji subset in JIS order (1191 = 湾), 1192-1212 level-2 kanji
# used in names; 1213 is a "100" icon and 1214-1215 are not characters (〓). Kana, Latin letters and digits in text are
# one-byte JIS X 0201 codes (not in this font). Derived by exact bitmap matches against the fonts of the other KOEI
# games in this repository, the rest by JIS-order alignment against system fonts, reviewed by eye and against ship,
# person and place names. Lines starting with # are comments.

# 提督の決断II ROM 格式

3 MB HiROM，無 header。以下位址：檔案位移（= CPU 位址 & 0x3FFFFF），`$bb:aaaa` 為 CPU 位址；未特別說明者為原版，
Rev 1 的對應位址見 `rom.py` 的 `REVISIONS`。程式是 C 編譯的 65816 碼，DP 暫存器 D = 0x0200。
標「推測」者未經驗證。

## 文字

- 雙位元組碼（首 byte 0x81–0x9F、0xE0–）：碼 c ≤ 0x8980 畫 glyph c − 0x8140；0x8981–0x913F 畫 glyph 0；
  c ≥ 0x9140 代表 0x8200 + 0x100·(c − 0x9140)（低 byte 為 0 的碼，$D3:0DE3）。
- 單位元組：ASCII，以及 JIS X 0201 假名 0xA1–0xDF（預設畫成平假名，ESC K 之後片假名，ESC H 切回）。ESC C x 換色；
  格式字串裡常見 `ESC C %c`（顏色本身是參數）。名稱表不含 ESC，遊戲印的時候外加 ESC K … ESC H。
- 字型：0x2B0000 起每字 32 bytes（16×16 1bpp，左上、右上、左下、右下 8×8），1216 字，對照見 `data/charset.txt`。
  0x8140（全形空白）遊戲直接跳過、不讀字型；其他碼都讀 glyph c − 0x8140（`verify_text.py` 實測 1216 字）。
  0x8981–0x913F 的碼（實測 8981、8A41、8C40、8FFF、9041、913F）畫 glyph 0。

## 劇本

10 個劇本，標題表每項「n:標題」，開始日期表：10 個年（word）、10 個月、10 個日；日期表 +40 起 10 bytes
（68 68 60 35 68 60 60 35 25 15）未解。
遊戲中的日期存在 $7E:21A7（年 − 1941）、$7E:21A8（月）、$7E:21A9（日）。劇本 1–3 在選單中以黃色顯示（キャンペーン・シナリオ），
其餘為ショート・シナリオ（旗標位置未找）。

### 載入程式

$CA:9702（參數：劇本號）用 memcpy（$D0:950F）把 20 段 ROM 複製到 WRAM bank $7E：

| 7336 | 0x046133 | 0xFDC | 是 | 基地 70 × 58 |

拠点記錄。

## 資料表（WRAM $7E）

- **艦型**（27）：+0 名 12、+14 圖、+15 水雷、+16 速度、+17 物資（推測，畫面顯示順序）、+18 國（0 日 1 米 2 英 3 蘭 5 ソ 8 独）、
  +19 艦種（艦種名表 8 項）、+20 対艦、+21 対空、+22..+25 装甲（上左右下）、+26 搭載。110–149 新型（速度 0）。
- **潜水艦型**（20）：+0 名 12、+14 圖、+15 水雷、+16 速度、+17 物資、+18 國、+19 装甲。
- **航空機**（18）：+0 名 14、+14 國、+15 種別（表 11 項）、+16 低 4 bit 戦闘、高 4 bit 航続、+17 旗標（未解）。
- **戦車**（12）：+0 名 11、+11：口径 = (b&3)+1、装甲 = (b>>2&3)+1、bit4 推測可用。
- **艦船**（36）：+0 名 14（「名 讀音」）、+14 艦型（FF 無）、+17 速度、+19 練度、+28 対艦、+29 対空、+30..+33 装甲，其他未解。
  0–254 中前段為就航艦，其餘為予備／建造中（就航艦船畫面：艦種、?、装甲[3]、対艦、対空、水雷（取自艦型）、速度、機数（計算，未解）、練度；
  予備艦船畫面：装甲 4 方向、艦種、対艦、対空、水雷（印 0）、速度、?（0）、練度）。
- **艦隊**（45）：+0 提督（FF 無）、+1 X、+3 Y、+5 任務（0x04 奇襲、0x07 哨戒、0x10 無し）、+25/+27 目標（奇襲：+25 = 目標基地；
  哨戒：目標座標）。+5 bit 4 = 在港，此時 +1 為所在基地號（艦隊一覧畫面印基地名）。
- **國家**（31）：+0 領袖名 13、+13 編號、+14 稱號 15、+29 對連合國友好度（對日 = 99 − 值）、+30 旗標。
- **國力**（60，日本／連合國）：+0 国民生産力、+3 基地維持費、+5..+9 情報／艦船／航空／兵器／工業技術力、
  +0x13/+0x19/+0x1F/+0x25 國家 bit mask（$C3:1086 種類 0–3）。外交情報畫面：對日「交戦状態」= 米國，或在連合國 +0x19；
  「軍事協定」= 日本 +0x1F；「援助協定」= +0x25；對連合國「軍事同盟」= 連合國 +0x19 或 +0x1F。遊戲開始後連合國的
  0x5C 從 +0x1F 移到 +0x19（推測 +0x19 =「参戦」）。外交費未解。
- **海軍予備**（48）：+0 海軍費、+2 軍需物資、+4 陸戦隊、+5 起 14 × [機種, 數 word]、+47 輸送船。
- **陸軍予備**（31）：+0 陸軍費、+2 物資、+4 歩兵師団、+5 戦車師団、+6 起 8 × [機種, 數 word]、+30 トラック。
- **基地**（58）：+0 名 11、+11 X word、+13 Y word（推測：座標與大地圖大致吻合，70 基地中 57 個距陸地 5 px 內，其餘多為
  位圖上沒畫出的小島）、+15 擁有國、+17 代碼（2 字 ASCII）、+20 原屬國、+22 生産力、+23 最大、+30 油（bit0-1）／鉱（bit2-3）
  0–3 = 無小中大、+31..+46 8 組 (index, 種類)（推測駐留部隊，種類 5 = 艦隊）、+48..+55 鄰接（<100 拠点，≥100 基地+100）。
- **拠点**（靜態表）：100 個名稱指標，之後 X word ×100、Y word ×100、旗標 ×100（bit0-1 地形 平地 町村 密林 山岳）、
  鄰接 5 bytes ×100；遊戲開始時組成 $7E:6972 的 23-byte 記錄（名 11、X、Y、擁有者 word、旗標、鄰接 5）。
- **提督**（17）：名 14 + 3 bytes 未解（0–29 日、30–59 連合國）；**將軍**（18）：名 14 + 4 未解（0–14 日、15–29 連合國）。
- **潜水艦單位**（40）：+0 名 14（如「伊1」）、+14 型（FF 無）、+16 水雷、+17 速度、+18 物資、+19 練度（推測）、+26/+28 X/Y、+35/+37 目標。
- **陸戦隊**（7）：+0（ROM FF，遊戲中 7F）、+1 兵力、+2 所在基地（推測）、+3 任務（ROM 02 防衛／04 無し，遊戲中 42／44）、
  +4 目標基地（FF 無）、+5 未解、+6 指揮官（將軍號，FF 無）。陸戦隊一覧驗證了 +1、+4、+6。
- **海軍兵力畫面** 14 個機種 slot 的顯示順序 [0,1,4,5,6,7,10,11 | 2,3,8,9,12,13]；陸軍 8 slot 依序。
- **艦型性能畫面**只列 110 類（日 48、米 40、その他 22），110–149 為新型兵器不列。

## 頭像

頭像 f（0–103）= LZ entry 753 + f，40×48（5×6 個 4bpp tile），$D4:6DBC(x, y, f)；調色盤 $D4:6D38：
f ∈ [30,59] ∪ [75,93] ∪ [99,…] 且 f ≠ 102 用第二組（連合國）。提督 i 用頭像 i，將軍 j 用 60 + j。
90–95 推測為各國領袖（目視），96–98 日本軍官、99–101 盟軍軍官（$D4:6CD8/6D13），102–103 剪影。
事件頭像 488–531（$D9:57FE 一次載 4 張，調色盤 $D4:D5E8）身分未知。

## 大地圖

LZ entry 0：1bpp 位圖，每行 80 bytes（640 px，MSB 先），1 = 海；前 360 行為地圖，座標 = 像素（拠点、艦隊、潜水艦座標）。
主畫面另載入 LZ 2、4、92、1041 圖塊（渲染未解）。遊戲在主畫面把 LZ 0 解壓到 WRAM $7F:8000（`verify_maps.py` 逐 byte 比對）。
`export.py` 輸出的 `world_map.png` 是這張位圖的前 360 行（海陸兩色），不是遊戲畫面的圖塊渲染。戰術（海戰／陸戰）地圖未解。

## 操作序列（tools/sequences.py）

- `TO_SCENARIOS`：開機 → 標題 NEW GAME → 劇本選單。
- `new_game(sc)`：down×sc、a（劇本）、a（說明）、a（大日本帝国）、a（初級）、設定畫面、9 次 a 跳過開場訊息與第一則建議 → 主畫面。
- 主畫面 `TOP`（x x）打開頂部選單：委任 配備 一覧 作戦 情報 公布 機能。
- `PERSONNEL`：作戦 → 人事；再按 a = 海軍提督；陸軍将軍要從提督列表 `b down a` 回人事選單選。

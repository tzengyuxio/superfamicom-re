# SFC 三國志IV ROM 格式

KOEI，1994，SFC。檔案 `roms/Sangokushi IV (Japan).zip`。

本文的偏移一律是**檔案偏移**（無 copier header 的 3 MB 映像）。CPU 位址寫成 `$bb:aaaa`，HiROM：檔案偏移 = `位址 & 0x3FFFFF`（`$C0:0000` = 檔案 0）。「推測」表示沒有獨立驗證過。

## 1. 硬體與引擎

| 項目 | 內容 |
|------|------|
| 標頭（`0xFFC0`） | `SANGOKUSHI 4`，map mode `31`（HiROM），SRAM 32 KB |
| 向量 | native NMI `$00:8FA4` |
| 函式呼叫 | 大部分模組經 `JSL $C0:8003`（函式號＋堆疊引數）分派，例如 `0x0E` 設定資料來源、`0x1E` 解壓到 WRAM |
| 操作 | 標題 → START（常被吃掉）→ a → 新しくゲームを始める（a）→ 劇本（↓ 選，a）→ 選君主地圖（游標在劉繇）→ a 開確認框（頭像）→ a（可）→ ↑ → a（決定）→ 設定 a × 5 → 第一回合（約第 12300 幀）。按鍵要按住 8–10 幀，太短常被吃掉 |

Mesen 的 savestate 只能在 exec callback 裡建立／載入，驗證腳本都掛在 NMI handler `$00:8FA4` 上；載入後第一輪不生效，第一項都做兩次再丟掉。

## 2. 壓縮資料

KOEI 的 LZ（和天翔記 `$C0:F194` 同一套），表在 `0xF037`，解壓程式 `$C0:F194`。直接用共用的 `tools/koei_lz.py`。資料分散在許多 3-byte 長指標表裡，本文各節列出用到的表。

## 3. 字型與文字

- **文字**是 Shift-JIS（cp932）。人名、地名用到的 JIS 外的字放在使用者外字區 `0xEB9F–0xEBFC`，由字形與用到它的人名判斷（`rom.EXT_CHARS`，47 字；`tools/ext_chars_sheet.py` 畫對照圖）：

  瓚 昱 彧 郃 蒯 傕 邕 汜 詡 鄧 兗 龐 繇 邈 騭 闞 玠 邢 歆 闓 禕 譙 琬 郝 琮 伷 褚 璜 邳 琦 彤 鄴 綝 諶 昕 笮 祜 毋 靚 頎 毗 宓 蹋（＋只有字形可對的 幷 釭 涪 榮）。`EBF8` 未辨識，`EBF9–EBFB` 是圓圈的「戦」「内」「軍」，`EBFC` 是圖示。
- **字型**：字碼表 `0x14B6A6`，1997 個遞增的 LE16 Shift-JIS 碼；字號 = 在表中的位置（`$C1:0DC0` 二分搜尋）。字形在 `0x20000 + 32 × 字號`，16 × 16 1bpp，4 個 8 × 8（左上、右上、左下、右下，每列 1 byte）。
- 劇本選單裡 `[`、`\` 是「年」「月」的字形。

## 4. 人物（`0x9AB18`，462 筆 × 35 bytes）

| 偏移 | 內容 |
|------|------|
| +0–8 | 姓名（cp932＋外字，0 補滿） |
| +9–19 | 讀音（半形片假名） |
| +20–21 | 頭像碼 LE16（§9） |
| +22–23 | 關係 LE16，`FFFF` = 無；≥ 1000 推測是義兄弟群組（張飛、関羽都是 1004） |
| +24 | 相性（推測） |
| +25 | 生年 − 100（劉繇 51 → 151 年） |
| +26 | 未解（推測血緣／家系） |
| +27–29 | 未解（不是特殊能力） |
| +30–34 | 統率、武力、知力、政治、魅力 |

遊戲直接讀這張表（Mesen 讀取追蹤：顯示劉繇時讀 `$C9:B536` = 第 74 筆）。

## 5. 劇本

6 個，選單文字在 `0xBB5A2`（`189[12\ 董卓、都洛陽を制す`，NUL 結尾）：

| # | 年月 | 標題 | 人物 |
|---|------|------|------|
| 1 | 189 年 12 月 | 董卓、都洛陽を制す | 182 |
| 2 | 194 年 11 月 | 飛将軍、中原に舞う | 222 |
| 3 | 201 年 10 月 | 劉備、新野に雌伏す | 222 |
| 4 | 208 年 9 月 | 臥龍、赤壁に飛翔す | 235 |
| 5 | 221 年 4 月 | 漢朝滅び三國鼎立す | 208 |
| 6 | 235 年 2 月 | 巨星、五丈原に墜つ | 181 |

選劇本時，遊戲從 3 張指標表各取第 sc 筆解壓到 WRAM：

| 內容 | 指標表 | WRAM | 紀錄 |
|------|--------|------|------|
| 劇本人物 | `0xCAB8A` | `$7E:73B2` | 17 bytes × 人數 |
| 都市 | `0x107B38` | `$7E:B872` | 87 bytes × 43 |
| 勢力 | `0x14D6B5` | `$7E:C70F` | 51 bytes × 25 |

解壓後遊戲還會改：勢力 +10/+11（未解）；劇本 5、6 的曹丕 劉備／曹叡 孫権 劉禅：勢力 +3 設 `0x40`、君主的特殊能力 bit 28（人物 +12 bit 4）。這幾位都是稱帝的君主（221 年的孫権沒有），推測是皇帝旗標。

### 5.1 劇本人物（17 bytes）

紀錄依讀音排序，其他表用「1 起算的紀錄號」指它。

| 偏移 | 內容 |
|------|------|
| +0–1 | 同串列的下一筆（`FFFF` = 結尾） |
| +2–5 | 多半是 0，未解 |
| +6 | 忠誠 |
| +7 | 所在都市 |
| +8 | 勢力（`FF` = 無） |
| +9–12 | 特殊能力，32-bit LE（§6） |
| +13–14 | 未解 |
| +15–16 | 人物編號（§4） |

### 5.2 都市（87 bytes）

| 偏移 | 內容 |
|------|------|
| +0 | 所屬勢力的都市串列：下一個都市（`FF` = 結尾） |
| +1–2 | 武将串列開頭（第一位 = 太守） |
| +3–4、+5–6 | 兩個無所屬人物串列（在野 A／B，差別未解） |
| +9–10 | 異民族人物串列 |
| +11–12、+13–14 | 兩個人物串列，意義未解 |
| +15 | 人口 / 100（LE16） |
| +17、+19、+21 | 金、兵糧、兵士（LE16） |
| +23 | 所屬勢力（`FF` = 無；和勢力的都市串列 258/258 一致） |
| +24–27 | 開発、治水、商業、技術 |
| +28 | 未解（1–3） |
| +29–31 | 民忠、士気、訓練 |
| +32、+34、+36、+38、+40 | 弩、強弩、軍馬、連弩、発石（LE16） |

所有人物都在某一個都市的某一個串列裡（6 劇本皆 100%）。強弩、連弩、発石、+23 在 WRAM 改寫寿春的欄位後由都市畫面確認。

### 5.3 勢力（51 bytes × 25）

| 偏移 | 內容 |
|------|------|
| +0–1 | 君主（1 起算的劇本人物紀錄號，`FFFF` = 空位） |
| +2 | 都市串列的第一個都市（`FF` = 無；下一個在都市 +0） |
| +3 | 皇帝旗標（推測，見上） |
| +7 | `FF` |
| +8 | 未解（0–19；異民族 19） |
| +12–29 | 對勢力 0–17 的友好度（對自己為 0） |

勢力 18–20 是空位，21–24 是異民族（南蛮王、羌王、烏丸王、山越王），友好度一律 `0x28`。本拠不在表內：`forces.csv` 用君主所在的都市。

## 6. 特殊能力

名稱表在 `0x7DC6C`（24 × 5 bytes）。位元由 `$C9:53E0` 起的程式反組譯得到，劉繇 `0x02020020` = 駆虎 落石 罵声 和畫面一致。

| bit | 能力 | bit | 能力 | bit | 能力 | bit | 能力 |
|-----|------|-----|------|-----|------|-----|------|
| 0 | 外交 | 6 | 流言 | 14 | 弓兵 | 20 | 風変 |
| 1 | 情報 | 7 | 焼討 | 15 | 海戦 | 21 | 混乱 |
| 2 | 人材 | 8 | 諜報 | 16 | 火計 | 22 | 連環 |
| 3 | 製造 | 12 | 歩兵 | 17 | 落石 | 23 | 落雷 |
| 4 | 作敵 | 13 | 騎兵 | 18 | 同討 | 24 | 修復 |
| 5 | 駆虎 | | | 19 | 天変 | 25 | 罵声 |
| | | | | | | 26 | 虚報 |

bit 28 是載入時給皇帝設的（§5）。

## 7. 都市基本表（`0xBB09D`，43 筆 × 29 bytes）

| 偏移 | 內容 |
|------|------|
| +0、+1 | 未解（**不是**地圖座標） |
| +2 | 未解旗標（00／0F／F0／40） |
| +3–7 | 名稱 |
| +8–13 | 讀音（半形片假名） |
| +14 | 0 |
| +15–28 | 相鄰都市，`FF` 補滿。順序有意義：野戰地圖用它的索引（§10） |

43 城依序：襄平 北平 代県 晋陽 南皮 平原 鄴 北海 濮陽 陳留 洛陽 弘農 長安 安定 天水 西涼 下邳 徐州 許昌 譙 汝南 宛 新野 襄陽 上庸 江夏 江陵 武陵 長沙 桂陽 零陵 寿春 建業 呉 会稽 廬江 柴桑 漢中 下弁 梓潼 成都 永安 江州。

**地圖位置**：`0x10A397`，43 × (x, y) LE16 像素，是把都市放到畫面中央用的捲動值。都市的城圖示（2 × 2 tile：`04 05`／`06 07`）在大地圖第 `((x + 112) / 8, (y + 96) / 8)` 格（43/43）；第一回合以寿春為中心時 BG 捲動是 (544, 336) = 寿春的 (536, 336) + (8, 0)。

## 8. 大地圖

一張 mode 7 平面（第一回合的 PPU 狀態：mode 7 矩陣 0.5 倍 = 放大 2 倍，捲動 (544, 336)；畫面底部的指令列是 mode 1 的 BG，推測用 HDMA 在畫面中切換模式）。`$C3:0A05` 載入，來源是 `0x1B5490` 的 2 個長指標：

| 指標 | 串流 | 內容 |
|------|------|------|
| `$DB:1AD1` | `0x1B1AD1` | tilemap 128 × 128 bytes（第 0–95 列有用 → 1024 × 768 像素） |
| `$DB:3533` | `0x1B3533` | 256 個 8bpp tile（每個 64 bytes，一 byte 一像素） |

調色盤（CGRAM 列）：3–7 = `0x12BFC8`（160 bytes）；12–13 = 水面動畫 4 幀 `0x12C3E8 + 0x40 × k`；14–15 = `0x12C0A8`。地圖只用到這幾列。

## 9. 頭像

40 × 48 = 5 × 6 個 4bpp tile 逐列排列，960 bytes。分派 `$C3:59B7`（引數 = 頭像碼；`$7E:5743` 存上一次的碼，相同就不重解）：

- **專屬頭像**（bit 15 清除，碼 0–338）：`$C3:5823`。碼 n 的串流在 5 張指標表之一：n < 72 → `0x1DFD6B`[n]；< 144 → `0x1FC80A`[n − 72]；< 216 → `0x25B1F3`[n − 144]；< 288 → `0x1ABF4A`[n − 216]；其餘 → `0x21A0CD`[n − 288]（51 筆）。有些是空的（全黑）。200 人用專屬頭像（最大碼 247）。
- **組合臉**（bit 15 設定，262 人）：`$C3:5303`。bit 0–3 = 包 p（16 包），4–5 = 上半 a，6–7 = 下半 b，8–10 = 眼 c，11–12 = 口 d（bit 13–14 一律 1）。包 p 是 `0x1ED9D4` 的串流 6p … 6p + 5（B0–B5；B0–B3 是整張臉）：
  1. cut = `$C3:8D8F`[p]（LE16）：out[0:cut] = B[a]，out[cut:960] = B[b]
  2. 眼：eo = `$C3:8DAF`[p]，長度 0x40（p ∈ 0 2 8 13）、0x20（p = 4）、否則 0x60：out[eo:eo + len] = B[c]；p = 4 另外 out[0x180:0x1E0] = B[c]
  3. 口：mo = `$C3:8DCF`[p]，長度 0x60（p ∈ 7 10 11 14 15）、否則 0x40：out[mo:mo + len] = B[d]；p ∈ 1 9 10 14 15 另外補一段（p = 10：0x2A0 起 0x60；p = 14：0x240 起 0x20；其他：0x220 起 0x20）

  所有範圍都是 32 的倍數，也就是以 tile 為單位，kaodata 匯出時直接當成 cell。
- **調色盤**（`$C3:598B`）：組合臉用 0 號；專屬頭像用 `0x10BBFB`[碼]（0 或 1）。調色盤 n 在 `0x12C4E8 + 32n`。選君主確認框把頭像放在 VRAM `0x440`、CGRAM 調色盤 3。

## 10. 戰場地圖

88 張，每張是 20 欄 × 11 列的六角格（奇數欄只有 10 格），載入程式 `$C7:5CA7`。指標表 `0xAE248`（`$CA:E248`）每張有 3 個串流：

| 串流 | 大小 | 內容 |
|------|------|------|
| m | 220 | 配置：每格 1 byte，`FF` 空，0–7 推測是部隊的初始位置（未解） |
| 88 + m | 220 | 地形：每格 1 byte（高、低 4 位元似乎分開編碼，未解） |
| 176 + m | 3520 | BG tilemap 兩層 40 × 22（LE16）：先 BG1（森林、道路等地物），後 BG2（地面） |

- **地圖選擇**：`$7E:3DAE` = 1 是野戰，0 是攻城。野戰地圖 = `0x13B737`[6 × 守方都市 + k]，k 是攻方在守方相鄰表（§7 +15）的位置（`$D1:9773`、`$D1:972F`）；45 張（0–44）。攻城地圖 = 45 + 守方都市（`$7E:3DAA` 存都市號，`$C7:5D24` 加 45）。
- **tile**（`$C7:5321`）：指標表 `0x14E540` 的串流 0（野戰，608 tile）或 1（攻城，368 tile），放在 VRAM tile `0x100` 起。
- **調色盤**：野戰 `0x13BBEE + 0xE0 × s`（調色盤 4、5、6，接著調色盤 7 的 4 幀動畫）；攻城 `0x13BF6E + 0x60 × s`（調色盤 4、5、6）。12 月用 s = 3；4 組推測對應四季（未驗證）。

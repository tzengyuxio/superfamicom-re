# SFC スーパー信長の野望・武将風雲録 ROM 格式

KOEI，1992，SFC。ROM 直接讀 `roms/Super Nobunaga no Yabou - Bushou Fuuunroku (Japan).zip` 內的 `.sfc`（1 MB，無檔頭）。

LoROM：檔案偏移 = `(bank & 0x7F) × 0x8000 + (位址 − 0x8000)`。本文的偏移一律是**檔案偏移**；`$bb:aaaa` 是 CPU 位址。資料沒有壓縮。標「推定」的欄位還沒用遊戲程式或畫面確認，標「未解」的只輸出原始值。

FC 版（`~/works/famicom-re/bushou/docs/ROM_FORMAT.md`）的劇本、國、大名、茶器、姓名、登場武將、戰場地形表在這裡幾乎原樣出現，差異在各節註明。

## 1. 程式

| 項目 | 內容 |
|------|------|
| 向量 | NMI `$00:832B`（存檔重播用這個位址） |
| p-code | 和 SFC 三國志II 同一套直譯器；p-code 讀資料的指令在 `$00:006F`（讀取追蹤看到的 PC 幾乎都是它） |
| 模組 | 戰場用 `hexmain`（載到 p-code 位址 `0x6000` 起）＋`hs1–hs10` 覆蓋模組（`hs4` 的基底 `0xC900`）。p-code 呼叫 `E9 lo hi n` |

### 1.1 檔案表（`0x7800`）

16 bytes 一筆：`[名稱 8][bank LE16][位址 LE16][大小 LE32]`，名稱第一個 byte 為 0 結束（同 SFC 三國志II）。`export.py` 輸出成 `files.csv`。

| 檔名 | 偏移 | 內容 |
|------|------|------|
| `basedata` | `0xCA42` | 2 個劇本區塊、姓名表、國名、登場武將、頭像區域表、調色盤…… |
| `grpmap` | `0x156B0` | 大地圖 BG2 tilemap（§6） |
| `hdata` | `0x37466` | 戰場地形（§7）、戰場 metatile、底圖、調色盤 |
| `hexmain` | `0x3F7BE` | 戰場主模組（含戰場名表，§7.4） |
| 其他 | | `root`、`chouki`、`openning`、`settei`、`kdata`、`kisetsu`、`cdata`、`command`、`cs1–cs11`、`hs1–hs10`、`sengo`、`shibou`、`ending` |

## 2. 文字與字型

文字是 2-byte big-endian 的字碼 `0x8140–0x84A3`（= 字型第 0–867 字），半形片假名 `0xA1–0xDF` 一個 byte（cp932），`00` 結束。

- 字型：16×16 1bpp，字碼 c 在 `0x85800 + 32 × (c − 0x8000)`（`$10:D800` 起），4 個 8×8 依左上、右上、左下、右下排列，每列 1 byte、MSB 在左。顯示「織田信長でよろしいですか」時追蹤讀取找到（`$11:B400` = 織 等）。
- 字的順序是 JIS X 0208 的子集：第一水準，然後從「瓊」（`0x848F`）起是第二水準，最後 9 個是外字。字元對照在 `data/charset.txt`：人名用到的 445 字由 FC 版姓名表（SJIS）對齊得到，其餘用系統字型在 JIS 順序的空檔內比對後人工確認（不確定：`8440` 冶／治、`83B0` 二、`8499` 靫）。
- **跳脫碼**：低位 byte 是 `00` 的字碼無法寫進字串（`00` 是結尾），改寫成 `85F0`／`85F1`／`85F2` = `8200`（君）／`8300`（瀬）／`8400`。例：穴山信君的「君」、茶器「黄瀬戸旅枕」的「瀬」。Mesen 確認（`verify_text.py`）。
- 外字（同 FC，每個 16×16 塞 1.5 個字）：

| 字碼 | 文字 |
|------|------|
| `849B 849C 849D` | 長宗我部 |
| `849E 849C 849D` | 香宗我部 |
| `849F 84A0` | 鳥屋尾 |
| `84A1 84A2` | 佐々木 |

## 3. 劇本（`basedata`）

| 劇本 | 名稱 | 區塊 | 姓名表 | 開局武將 | 登場武將串列 |
|------|------|------|------|------|------|
| 1 | 戦国の動乱（1555 年 3 月） | `0xCA42` | `0x10580` | 250 | `0x15008`（120 筆） |
| 2 | 信長包囲網（1571 年 3 月） | `0xE5CA` | `0x12578` | 255 | `0x153D0`（91 筆） |

區塊 `0x1B88` bytes。遊戲把區塊 +4 … +`0x1B8C` 複製到 WRAM `$7E:DC04`（讀取追蹤確認），所以區塊偏移 k 就是 `$7E:DC00 + k`，區塊內的指標都是這種 WRAM 位址。

| 區塊偏移 | 內容 |
|------|------|
| `+5` | 劇本編號 |
| `+6` | 年 − 1476 |
| `+7` | 月 |
| `+0x008` | 國 48 × 32 bytes（§3.1） |
| `+0x608` | 茶器 48 × 3 bytes（§3.4） |
| `+0x698` | 大名 48 × 32 bytes（§3.3） |
| `+0xC98` | 武將 15 bytes × 254 格（§3.2） |

FC 版的國表從 `0x007`、茶器從 `0x607` 起；SFC 都往後 1 byte（FC 文件的茶器 `[值][指標]` 其實就是 `[指標][值]` 錯開 1 byte 的讀法）。

載入時遊戲會改寫的位置（`verify_scenarios.py`）：國 +19（重新計算）、國 +21（= ROM 值 << 6）、國 +31（10 國設成 4）、劇本 2 的大名 +31（重新編號）、最後一格武將之後的 1 byte。其餘 7048 bytes 中的每個 byte 都和 ROM 相同。

### 3.1 國（48 × 32 bytes）

`tools/province_probe.py` 把尾張的欄位改成各自的偏移後截圖對照；開局的數值也和尾張的國畫面一致。

| 偏移 | 欄位 |
|------|------|
| 0–1 | 第一位武將的指標（武將以 next 指標串成串列；畫面的「武將」人數就是串列長度） |
| 2–3 | 第二個指標（未解，多為 0） |
| 4–5 | 金 |
| 6–7 | 米 |
| 8–9 | 石高 |
| 10 | 治水 |
| 11–12 | 町 |
| 13 | 文化（眼睛圖示） |
| 14–15 | 技術（鎚子圖示） |
| 16 | 民忠（FC 文件寫成兵忠，兩者寫反） |
| 17–18 | 城 |
| 19–21 | 未解（19 由載入程式計算、21 載入時左移 6 位） |
| 22–23 | 大名記錄的指標（`$7E:DC00 + 0x698 + 32 × 大名`；0 = 無主） |
| 24–25 | 兵 |
| 26–27 | 鉄砲 |
| 28 | 訓練 |
| 29 | 兵忠 |
| 30–31 | 未解（31 載入時改寫） |

### 3.2 武將（15 bytes）

第 i 格的姓名指標 = 姓名表第 i 筆（指標值 = 姓名記錄偏移 − `0xCA42`，`rom.generals` 會 assert）。對照畫面：織田信長（劇本 1 第 119 格）政治 95、戦闘 87、教養 80、魅力 97、野望 100、年齢 21；出陣選將清單的柴田勝家等 6 人。

| 偏移 | 欄位 |
|------|------|
| 0–1 | 同國下一位武將的指標（0 = 結尾） |
| 2–3 | 姓名指標 |
| 4 | 政治 |
| 5 | 戦闘 |
| 6 | 教養 |
| 7 | 旗標（未解；FC 推定 bit 3 = 持有茶器） |
| 8 | 未解 |
| 9 | 所在國 |
| 10 | 所屬大名 |
| 11 | 忠誠（大名本人 100） |
| 12–14 | 0（未解） |

FC 版是 13 bytes：SFC 拿掉了 FC 的 byte 9（固定 0），後面多 3 個 0。

### 3.3 大名（48 × 32 bytes）

| 偏移 | 欄位 |
|------|------|
| 0–1 | 大名本人的武將指標（0 = 空格） |
| 2–4 | 同盟的大名編號（`FF` = 無）；畫面上「浅井家」等同盟顯示對得上（織田 → 浅井，北条／武田／今川三國同盟） |
| 5–28 | 48 個 4 bits，每家一個（自己 = `F`）；對角線以下只有 0 或 8。意義未解 |
| 29 | 未解（50／60／70／100） |
| 30 | 未解 |
| 31 | 大名編號；劇本 2 載入時重新編號（未解） |

### 3.4 茶器（48 × 3 bytes）

`[持有者武將指標 LE16（0 = 無）][值（未解）]`。名字見 §4。

## 4. 姓名表（20 bytes）

| 偏移 | 欄位 |
|------|------|
| 0–6 | 姓（字碼，0 補齊） |
| 7–13 | 名 |
| 14 | 魅力 |
| 15 | 野望 |
| 16 | 未解（FC 推定為相性） |
| 17 | 生年 − 1476 |
| 18–19 | 頭像碼（LE16，§5） |

| 範圍 | 劇本 1 | 劇本 2 |
|------|------|------|
| 開局武將 | 0–249 | 0–254 |
| 改名後的姓名 | 255 徳川家康、256 豊臣秀吉 | 255 徳川家康、256 豊臣秀吉 |
| 登場武將 | 257 + k（FC 是 256 + k） | 257 + k |

登場武將之後空 20 bytes，接著 48 個茶器名（13 bytes）。ROM 裡沒有讀音。

### 4.1 登場武將（8 bytes，推定）

`[登場年 − 1476][國（FF = 未定）][未解][政治][戦闘][教養][旗標][未解]`，`00` 結束。結構與 FC 相同，所在國吻合（多賀谷政広 → 下総…徳川秀忠）。和 FC 比，劇本 1 少了 FC 第 111 筆（`6d ff 1b 20 5a 50 40 00`），劇本 2 少了 FC 第 69 筆，有些國不同。遊戲中沒有等到登場，屬推定。

## 5. 頭像

40×48 = 5×6 個 4bpp tile（列優先，960 bytes），遊戲直接從 ROM DMA 到 VRAM word `0x6400`，tilemap 用 BG 調色盤 5。調色盤只有一組：`0x174DC`（16 色）。頭像碼取自姓名記錄 +18。

### 5.1 專屬頭像（碼 < `0x8000`，0–179）

頭像 f 在 bank `0x16 + f // 34` 的第 `f % 34` 張：偏移 `lorom(0x16 + f // 34, 0x8000 + 960 × (f % 34))`。信長 = 25（`0xB5DC0`）。

### 5.2 組合臉（碼 bit 15 = 1，用到 278 個）

| bits | 內容 |
|------|------|
| 0–2 | 頭（8 個） |
| 3–4 | 上（頁 0–3） |
| 5–6 | 下 |
| 7–8 | 眼 |
| 9–10 | 鼻 |
| 11–12 | 口 |

頭 h 的第 p 頁在 `0xA8000 + (4h + p) × 960`，每頁是一張完整的 40×48 臉。遊戲依序複製「上、下、眼、鼻、口」五段連續的格（後面的蓋過前面的；碼 `0x8002` 的 DMA 紀錄確認），每段取該區選中那頁的同一格。區域表在 `0x1793C`，8 頭 × 22 bytes：`[LE32 未解（0x1000／0x1400／0x1800）][上格數][下起點][下格數][眼起點][眼格數][鼻起點][鼻格數][口起點][口格數]`（各 LE16，上從第 0 格起）。

| 頭 | 上 | 下 | 眼 | 鼻 | 口 |
|------|------|------|------|------|------|
| 0 | 0–19 | 20–29 | 10–12 | 15–17 | 21–22 |
| 1 | 0–19 | 20–29 | 11–13 | 17–18 | 22–23 |
| 2 | 0–14 | 15–29 | 10–12 | 15–16 | 21–22 |
| 3 | 0–14 | 15–29 | 10–12 | 15–16 | 20–21 |
| 4 | 0–14 | 15–29 | 12–14 | 17–18 | 22–23 |
| 5 | 0–14 | 15–29 | 10–12 | 15–17 | 20–22 |
| 6、7 | 0–14 | 15–29 | 12–14 | 18–19 | 23–24 |

驗證（`verify_faces.py`）：180 個專屬碼、278 個用到的組合碼逐一寫進信長的姓名記錄，國畫面上的 VRAM tile 與 CGRAM 調色盤 5 全部一致。

## 6. 大地圖

選大名畫面與國畫面：BG mode 2，BG1 tilemap `0x0000`／CHR `0x2000`，BG2 tilemap `0x0C00`／CHR `0x4000`（word 位址），BG 調色盤 0–7 在 `0x1743C`。

- BG2（外框與海）：30 × 21 個 tilemap 項目在 `0x15A6C`（`grpmap` 內），畫在 tile (1, 2)。tile n < `0x200` 來自 `0x84000 + 32n`，其餘來自 `0x90000 + 32(n − 0x200)`。
- BG1（陸地）：28 × 17 tile 的點陣，tile 列優先放在 `0x84000`，調色盤 7，畫在 tile (2, 5)。遊戲只把色 7 的像素改塗成各勢力的顏色（驗證時 9214 個像素）。

## 7. 戰場

一場合戰先在野戰地圖打，籠城後改到城地圖（同 FC）。兩者都是六角格，奇數行（column）往下錯半格。表都在 `hdata`。

| 遊戲變數 | 意義 |
|------|------|
| `$7E:F7CB` | 戰場所在國 |
| `$7E:FC02` | 地形格（每格 1 byte）；遊戲把部隊所在格加上 `0x40`、把一格改成 `0x0A`／`0x4A`（推定為本陣） |
| `$7E:FC9C` | 城地圖的第二層 |

### 7.1 野戰地圖（`0x3746A`，48 張 × 154 bytes，14 × 11）

載入：`hs4` 的 p-code（`hs4+0x4B1`）把 `hdata + 4 + 154 × $F7CB` 複製到 `$FC02`；美濃的地圖在第 6915 幀被讀取。地形：7 平地、8 丘陵、9 林、B 海・湖、C 山、D 川（同 FC）。

### 7.2 野戰畫面

BG mode 2，BG2 tilemap word `0x0C00`、CHR word `0x4000`。

1. 底圖：第 r 列（0–29）= bank 7 `$DEC6 + 64r`（`0x3DEC6`）的 32 個項目。
2. 狀態列：bank 7 `$DB4E`（`0x3DB4E`）4 列 × 30 項目，畫在 tile (1, 1)。
3. 第 c 行第 r 列的格：2×2 metatile 畫在 tile (2 + 2c, 5 + 2r + (c & 1))。metatile = bank 7 的 4 個 LE16 tilemap 項目（左上 右上 左下 右下）：

| 地形 | metatile | 備註 |
|------|------|------|
| 7 | `$D20A` | |
| 8 | `$D212` | |
| 9 | `$D21A` | |
| B | `$D22A`；上方是 B 或第一列時 `$D222` | |
| C | `$D232` | |
| D | `$CDCA`；上方是 B／D 或第一列時 `$CDFA` | |
| A | `$D3EA` | 遊戲在載入後放上的格 |
| 有部隊（+`0x40`） | `$D682`／`$D68A`／`$D692` 等 | 匯出不畫 |

CHR（遊戲進入戰場時的 DMA，`(ROM 偏移 → VRAM word, bytes)`）：`0x5C120 → 0x4000, 0x1120`、`0x5E860 → 0x4E00, 0x400`、`0x5D240 → 0x5000, 0xA80`、`0x5BF80 → 0x5600, 0x1A0`、`0x58E40 → 0x5800, 0xC00`、`0x5DCC0 → 0x6800, 0xBA0`、`0x5B380 → 0x7800, 0xDA0`。BG 調色盤 0–5：`0x3CEEA`（`$07:CEEA`，0xC0 bytes 到 CGRAM 0）。

驗證（`verify_maps.py`）：48 張地圖逐一換進美濃的合戰，遊戲畫出的 BG2 tilemap（32 × 28，有部隊的格除外）、CHR、調色盤全部和上述規則一致。

### 7.3 城地圖（`0x393B2`，49 張 × 143 bytes，13 × 11；第二層 `0x3B0BE`）

載入：`hexmain+0x4430` 的 p-code 把 `hdata + 0x1F4C + 143 × n` 複製到 `$FC02`、`hdata + 0x3C58 + 143 × n` 複製到 `$FC9C`。n = `$F7CB`；`$F7CB = 0x18`（近江）且 `$F7C4 & 0x40`、`$F7C8 = 0xFF` 時 n = 48（安土）。這段是讀 p-code 推得的，**沒有實際進入籠城戰**，城地圖的畫面組裝（metatile、底圖）未解，`export.py` 只輸出地形值示意圖。地形值 0、1、3–9、C、D 與 `0x84`–`0x86`，第二層 `0x00–0x6B`，意義未解。

### 7.4 戰場名（`hexmain`，推定）

`0x459CB`（`hexmain+0x620D`）49 個 LE16 指標 = 各國野戰地名（美濃 = 墨俣，48 空白），`0x45B54`（`hexmain+0x6396`）49 個 = 城名（美濃 = 稲葉山城，48 = 安土城）。指標是 p-code 位址，ROM 偏移 = `0x3F7BE + 指標 − 0x6000`。名字與 FC 版同一份，但合戰中沒有看到顯示的地方，屬推定。

## 8. 操作序列（Mesen，`tools/drive.py` 語法）

按鍵要按住約 10 幀才穩。

| 目的 | 序列 | 到達幀 |
|------|------|------|
| 選大名地圖（劇本 1，游標在織田） | `w900 start:10 w300 a:10 w200 a:10 w200 a:10 w200 a:10 w200 up:10 w60 a:10 w200` | 約 2480 |
| 劇本 2 | 在第二個 `a` 之前加 `down:10 w30` | |
| 開局（尾張國畫面，頭像 DMA 在 3876） | 上一列＋`a:10 w200 a:10 w200 a:10 w300 a:10 w900` | 約 3810–4200 |
| 情報 → 武將 → 信長 | 開局＋`right:10 w30 right:10 w30 right:10 w30 a:10 w100 a:10 w100 a:10 w100` | |
| 出陣美濃（野戰畫面） | 開局＋`right:10 w30 a:10 w100 down:10 w30 down:10 w30 a:10 w100 up:10 w30 a:10 w100 a:10 w100 down:10 w30 a:10 w100 b:10 w100 a:10 w100 a:10 w100 a:10 w100 b:10 w100 a:10 w100 a:10 w200 a:10 w200 a:10 w300 a:10 w300` | 地圖 6913–7050 畫好 |

## 9. 未解

- 季節調色盤（只看過 3 月）。
- 武將 byte 7（旗標）、byte 8、byte 12–14；姓名表 byte 16；登場武將 byte 2、7（以及登場武將本身未在遊戲中確認）。

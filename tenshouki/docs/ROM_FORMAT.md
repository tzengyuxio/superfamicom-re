# SFC 信長の野望・天翔記 ROM 格式

KOEI，1996，SFC。檔案 `roms/Nobunaga no Yabou - Tenshouki (Japan).zip`。

本文的偏移一律是**檔案偏移**（無 copier header 的 3 MB 映像）。CPU 位址寫成 `$bb:aaaa`，HiROM：檔案偏移 = `位址 & 0x3FFFFF`（`$C0:0000` = 檔案 0）。

## 1. 硬體與引擎

| 項目 | 內容 |
|------|------|
| 標頭（`0xFFC0`） | `NOBUNAGA TENSHOUKI`，map mode `31`（HiROM、FastROM），型別 `02`（ROM＋RAM＋電池），SRAM 32 KB |
| 向量 | native NMI `$00:8FC3`、IRQ `$8C05`；emulation RESET `$800F` |
| 操作 | 標題 → START → 新しくゲームを始める → 劇本 → 大名。第一回合的主選單：→ 4 次是「情報」，再 → 3 次是「家臣」 |

Mesen 的 savestate 只能在 exec callback 裡建立／載入，驗證腳本都掛在 NMI handler `$00:8FC3` 上。

## 2. 壓縮資料（`0x1F95A4`）

659 個 3-byte 長指標（bank `$C0–$EF`），指向壓縮串流，由 `$C0:F194` 解壓（`rom.decompress`）。LZ 類：

- 16-bit 位元窗 W 從串流的 LE16 讀入；旗標 byte 與字面值 byte 從同一個指標夾在中間讀
- 旗標 bit（MSB 先）：1 = 字面值；0 = 從 distance + 1 處往回複製 length + 1 bytes
- length 與 distance 由 W 前綴碼決定，查 bank `$C0` 的表：`0xF037`（length 值）、`0xF077`（length 位元數）、`0xF0B6`（length shift）、`0xF0BE`／`0xF17E`（近距離）、`0xF187`／`0xF18C`（遠距離）
- length 值 `0xFF` 結束

本文的「entry n」都是這張表第 n 個解壓結果（`Rom.entry`）。

| entry | 內容 |
|-------|------|
| 7、8 | 劇本 1、2 的城（§5） |
| 9、10 | 劇本 1、2 的人物（§4.3） |
| 13、14 | 劇本 1、2 的軍団（§6） |
| 19 | 大地圖 tile（§8） |
| 213–326 | 16×16 圖示 |
| 327 | 家紋 tile |
| 328–346 | 組合臉 19 包（§7） |
| 347–658 | 專屬頭像 P000–P311（§7） |
| 25–50、190–212 | 推測是合戰畫面用圖，未解 |

## 3. 劇本

2 個：信長初陣（1547）、信長包囲網（1571）。標題字串在 `0xBECEA`（Shift-JIS）。年齢 = 劇本年 − 生年 + 1。

## 4. 人物（700 人，編號 0–699）

### 4.1 人物主表（`0xD0F80`，14 bytes）

| 偏移 | 內容 |
|------|------|
| 0–1 | 頭像碼 LE16（§7）。同時當作親族關係的 id |
| 2、3、4 | 政治、戦闘、智謀的**上限 ÷ 2** |
| 5 | 魅力 |
| 6 | 野望 |
| 7 | 生年 − 1454 |
| 8–9 | 父親的頭像碼 LE16（`FFFF` = 無） |
| 10–11 | 未知 |
| 12–13 | 12 bit 旗標，未解 |

### 4.2 姓名（`0xE1DF8`，19 bytes × 1400）

每劇本一份：劇本 s 的人物 id 在 `id + 700 × s`（少數人兩劇本寫法不同）。

| 偏移 | 內容 |
|------|------|
| 0 | 旗標（未解） |
| 1–6 | 姓，Shift-JIS，`00` 結尾 |
| 8–13 | 名，Shift-JIS，`00` 結尾 |
| 15 | 生年 − 1440 |
| 16–18 | 未知 |

### 4.3 劇本人物（entry 9、10，700 × 35 bytes）

載入到 WRAM `$7E:3F70`。ROM 把在場的人（劇本 1 有 333 人、劇本 2 有 406 人）排在前面；載入程式只複製這些、清空其餘，並重建串列連結。姫與未登場的人在執行期放在別處（未找到）。

| 偏移 | 內容 |
|------|------|
| 0–1 | 人物 id |
| 2–3、4–5 | 同城串列的前一位／下一位（1 起算的記錄號） |
| 8、9、10 | 政治、戦闘、智謀，**上限的百分比**。顯示值 = pct × (上限 ÷ 2) // 100（例：74 × 70 // 100 = 51） |
| 11 | 忠誠 |
| 12–13 | 勲功 LE16（999 = 無） |
| 15 | 大名號（255 = 無） |
| 17–18 | 軍団 LE16 |
| 19–20 | 城 LE16（1 起算，0 = 不在場） |
| 23、24、25 | 兵士、訓練、士気 |
| 26 | 部隊：0 足軽隊、1 騎馬隊、2 鉄砲隊 |
| 27 | 仕官年數 |
| 31–32 | 適性 LE16，每項 3 bit，依序足軽、騎馬、鉄砲、水軍；0–5 = E D C B A S |
| 33 | bit 0–2 狀態：0 大名、1 軍団長、2 武将、3 隠居?（只有 1571 的浅井久政）、4 浪人、5 姫、6 未登場；bit 3–5 身分：1 大名、2 宿老、3 家老、4 部将、5 侍大将、6 足軽頭 |

某大名的当主＝該大名號下狀態為 0 的人。

## 5. 城（128 城）

**城名**（`0xD0480`）：2 劇本 × 128 × 11 bytes，Shift-JIS 9 bytes＋2 bytes 未知。字尾寫死在 `$C4:20CB`（1 起算的城號）：10、42 加「館」；7、86 不加；60 加「本願寺」；128 不加；其他加「城」。石山、室町御所、観音寺、稲葉山會隨事件改名（石山本願寺／石山城、二条城、安土城、岐阜城），這裡用劇本開始時的名字。

**城的地圖資料**（`0xD0000`）：128 × 9 bytes，兩劇本共用。

| 偏移 | 內容 |
|------|------|
| 0 | 国 |
| 1–6 | 未知（+2–3 看起來是 LE16，+4 是 0／1） |
| 7、8 | 大地圖 tile 座標 x、y（城圖示右上角那一格） |

**劇本城資料**（entry 7、8，128 × 23 bytes），載入到 WRAM `$7E:882C`：

| 偏移 | 內容 |
|------|------|
| 0–3 | 串列連結 |
| 4–5 | 城內第一位人物（1 起算的記錄號，載入時重建） |
| 8–9 | 軍団 LE16 |
| 10 | 城郭 |
| 11–12 | 石高 LE16 |
| 13 | 商業 |
| 14–15 | 人口 LE16 |
| 16 | 民忠 |
| 17 | 徴兵 |

人口與徴兵在開局時會重新計算。

## 7. 頭像

40 × 48 = 5 × 6 個 4bpp tile，逐列排列，960 bytes。由 `$C3:2DF5` 組到 WRAM `$7F:0B40`；武将畫面放在 VRAM tile `0x522` 起，用 CGRAM 調色盤 9。

**調色盤**：3 組 × 16 色 BGR555 在 `0x1FA1DD`。專屬頭像的調色盤編號在 `0x19205`（每個碼一個 LE16），組合臉的在 `0x3F218`（每包一個 LE16）。

**專屬頭像**（頭像碼 bit 15 = 0）：entry `347 + (碼 % 410)`。共 312 張，人物用到 0–295。

**組合臉**（bit 15 = 1）：包號 = `(碼 & 0x1F) % 19`，entry `328 + 包號`，每包 4 張完整的臉（4 × 960 bytes）。組法（`$C3:2983`）：

1. 上半：從第 `(碼 >> 5) & 3` 張取前 `160 × 上半列數` bytes
2. 下半：其餘從第 `(碼 >> 7) & 3` 張取
3. 只有第 0 包：tile 20 從上半那張取
4. 眼：從第 `(碼 >> 9) & 3` 張取 `0x140 + 32 × 眼位置` 起 `0x60` bytes（3 個 tile）
5. 口：從第 `(碼 >> 11) & 3` 張取 `0x280 + 32 × 口位置` 起 `n × 32` bytes

每包的上半列數、眼位置、口位置在 `0x3F1CC`（19 × 3），口寬 n 在 `0x3F205`（19 bytes）。

## 8. 大地圖

兩張未壓縮的 150 × 65 BG tilemap 在 `0x22339D`（LE16 一格）：先地形，接著道路（疊在地形上，色 0 透明）。tile 號 n 是 entry 19 的第 `n − 435` 個 tile（VRAM tile 435–735）；調色盤 3–5 在 `0x1F9E1D`。調色盤 5 的色 4、5、9、15 會循環變色，ROM 存的是第 0 格。

回合畫面上，地形 BG 的 tilemap 在 VRAM word `0x5400`、道路 BG 在 `0x5800`，內容是以畫面為準的 32 × 28 格（不是環形緩衝）。道路 BG 同時放遊戲的視窗（tile < 435）和城的標記（tile ≥ 736）。

B 鍵的縮小地圖是另一套 tile，未解。

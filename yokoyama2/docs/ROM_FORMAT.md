# SFC 横山光輝 三国志2 ROM 格式

エンジェル，1993，SFC。檔案 `roms/Yokoyama Mitsuteru Sangokushi 2 (Japan).zip`（只有一版），1.5 MB LoROM（FastROM）。不是光榮的作品：引擎是前作 `yokoyama/`（横山光輝 三国志，1992）的延續，16-bit 自訂字碼、同一種 LZSS、sprite 組合頭像、mode 7 大地圖都沿用，但程式重新組譯過（前作的位元組樣式在這片 ROM 裡一個都找不到），字型重畫，各表格式也改了（§11）。

本文的位址一律寫成 CPU 位址 `$bb:aaaa`（程式在 FastROM 的 `$80–$AF` bank 執行），LoROM：檔案偏移 = `(bb & 0x7F) × 0x8000 + (aaaa − 0x8000)`（`rom.off()`）。WRAM 寫成 `$xxxx`（bank `$7E`）或 `$7E:xxxx`。「推測」表示沒有獨立驗證過；「未解」表示意義不明，匯出時只輸出原始值。

| 項目 | 內容 |
|------|------|
| SHA-1（.sfc） | `0bddc92c8ac5028d732c2104d67afe587d9e4908` |
| 標頭（`$00:FFC0`） | `SFX ﾖｺﾔﾏ ﾐﾂﾃﾙ ｻﾝｺﾞｸｼ2`，map mode `30`（LoROM、FastROM），ROM 型 `02`（ROM＋SRAM＋電池），SRAM 8 KB，版本 0 |

## 1. 硬體與引擎

| 項目 | 內容 |
|------|------|
| 向量 | native NMI `$00:823A`（第一條是 `REP #$30`，`tools/replay.py` 自動掛在 `$00:823C`），reset `$00:8000` |
| 程式 | 手寫組合語言：JSR／JSL、直接頁 `$00–$FF` 當暫存；乘法用 `$4202`（`$81:A543` = A × 24 人物紀錄、`$81:A557` = A × 20 國紀錄） |
| 文字輸出 | `$80:8C2E`：A = 一個字碼（§3）。所有文字驗證都攔它 |
| LZSS 解壓 | `$81:A8F0`：A = 來源位址、X = bank，輸出到 `$7E:8000`（§2）；`$81:A988` 是 JSL 進去的包裝 |
| 16-byte 交錯 | `$81:A98C`：把 `$7E:8000` 起解壓結果的每 16 bytes 改排成 [0, 8, 1, 9, …, 7, 15]（前 8 bytes 放偶數位置、後 8 bytes 放奇數位置）。4bpp 圖與 mode 7 圖都先這樣存 |
| OAM／CGRAM 影子 | OAM `$7E:2000`（544 bytes），CGRAM `$0400`（512 bytes；OBJ 調色盤 0 = `$0500`） |

### 操作序列（`tools/sequences.py`，按鍵按住 10 幀，之後放 20 幀，和 `tools/replay.py` 相同）

| 名稱 | 內容 |
|------|------|
| `TO_SCENARIOS` | 標題（約第 1800 幀後才接受 START）→ START → START → a（最初から始める）→ 劇本選擇 |
| `scenario(k, r, d)` | 劇本 k（189 桃園の誓い／200 群雄割拠／215 三国時代，下移）→ 君主選擇（清單，下移；第 0 項在三個劇本都是劉備）→ 難易度（上級 中級 初級 エディット）→ 開場文字（3 次按鍵）。劇本載入程式在開場文字結束時執行 |
| `TO_MAP[k]` | 再按 `TURN_PRESSES[k]` 次（3／2／0：開局事件與「○○軍戦略中」，每個都等一次按鍵）→ 玩家（劉備）的第一個月，地圖上出現游標。按鍵次數跟時機有關（亂數），是用暴力搜出來的 |
| `DETAIL_STEPS` | 地圖 → a（國的面板與指令 政略 軍略 政策）→ a（政略）→ 下、a（人事）→ a（人材）→ a（選択：武將列表，依政治力排序）→ X（第一位的武將詳細畫面：姓名、所屬、讀音、官位、全部欄位、頭像） |

- 地圖上的游標是 `$0160`／`$0162`（LE16，1024 × 1024 地圖的 pixel；方向鍵一次 24）。X = 游標所在國的資訊畫面；B 返回時大地圖會重建（`$91:8000` 再跑一次）。
- 國的武將列表在**打開國的面板時**建立：要改人物的 WRAM，savestate 必須存在面板打開之前（存在人事／人材選單時改了沒有效果）。
- 選單剛出現時立刻按「下」會被吃掉，要先等 30–60 幀。

## 2. LZSS 壓縮（`$81:A8F0`，`rom.lz`）

和前作完全相同：開頭 LE16 = 輸出大小，接著是旗標 byte（LSB 先），每個旗標：1 = 一個字面 byte；0 = 一個 LE16 字 w，從 `w >> 4` bytes 之前複製 `(w & 15) + 3` bytes（指到開頭之前的位置讀成 0）。

開機到第一個月的地圖之間遊戲解壓 37 個串流（`verify_lz.py`）：`$87:8000`–`$87:DEFF`（標題）、`$91:827D`（大地圖）、`$91:D034`–`$91:E48B`、`$94:9876`–`$94:A53A`、`$9B:8000`–`$9B:A553`、`$9C:8000`、`$9C:CC58`、`$9D:8880`、`$9F:9DEA`、`$A7:8000`–`$A7:F270`，內容沒有一一辨認。程式裡另外還有約 30 個沒在這段用到的串流（例：`$84:DB76`／`$84:DF2A`／`$84:E489` 載入的 `$AB:8000`、`$AC:8000`、`$AD:8000`，各 24 KB 4bpp 圖＋32 × 32 tilemap＋調色盤，是事件／結局的場景圖，例如宮殿城牆；`$8A:F661`、`$8A:F713` 載入的 `$A4:84F6`、`$9D:ADD4`；`$85:82D2` 起的 `$A8:xxxx`）。頭像**不是**壓縮資料。

## 3. 字型與文字

- **字碼**：16-bit LE，`0x0000` 結束，`0x000A` 換行。
  - `0x200–0x5FF`：16 × 16 字，`$9A:8000 + 32 × (code − 0x200)`（1bpp，4 個 8 × 8：左上、左下、右上、右下，每列 1 byte）。`$80:8C8B LDA $9A8000,X`。
  - `0x100–0x1FF`：8 × 16 半形字，`$99:A000 + 16 × (code − 0x100)`（`$80:8CBE`）。
  - `< 0x100` 控制碼（`$80:8D03`）：F0 武將名（`$0109`）、F1 國名（`$0113`）、F2／F6 3 位數（`$67`／`$71`）、F3／F7 4 位數（`$69`／`$73`）、F4／F8 5 位數（`$6B`／`$75`）、F5／F9（`$6D`／`$77`）；其他值當作武將名 `$010B`。
  - `0x600` 以上會讀到 `$9B:0000` 以後（LoROM 那裡不是 ROM），不是文字。
- **字表** `data/charset.txt`（16 字一行）：0x100–0x1FF 半形（數字、英文、片假名、平假名、狀態欄用的小字）；0x200–0x5FF 全形（假名、人名與地名用漢字、一般漢字）。字形和前作不同（重畫過、字碼配置也不同），全部重新人工判讀（`tools/charset_sheet.py` 畫字形與字元對照）。人名用漢字從 0x313 起照名表順序配置，名表照讀音的五十音排序，國名有讀音，都可以交叉檢查。
  - 222 涼／31E 凉、32B 侯／352 候、3D9 郃 是不同字形，照字形寫。
  - 1CA–1CE、1D0–1D2 是較小的半形 政 法 武 統 兵 忠 士 攻；1E0–1E9、1F0–1F9 是另外兩種數字。
  - 1D3–1D5 是圖示（馬Lv 弓Lv 歩Lv），寫成 □。1FA–1FF 是半形合字：六個一起畫出「ショカツリョウ」（諸葛亮的讀音），`rom.LIGATURE` 把 1FA 讀成整串、1FB–1FF 讀成空字串。
  - 沒把握的字形：2EC 朦、522 粋、571 具、579 冑、59B 滅（第二個字形）、5D2 闌、5FB 羲。
- 訊息字串沒有整理成表（例：`$80:FE00` 起是指令名稱 器 兵器 計略 行軍 会議 農業 …，一個字串一個名稱）。

## 4. 名表（`$8C:8000`，239 筆 × 8 bytes）

| 偏移 | 內容 |
|------|------|
| +0–1 | 第一字（字碼） |
| +2–3 | 第二字 |
| +4–5 | 第三字（`0x200` = 無；239 筆裡 214 筆是兩字名，例：諸葛亮 = 諸 葛 亮、劉備 = 劉 備 0x200） |
| +6–7 | 讀音字串的指標（`$8C:xxxx`，半形片假名字碼，0 結束） |

前作是「姓、第二字（0x200 = 無）、名」，本作改成照順序填、空的放最後。index 就是人物編號 p：0–222 照讀音的五十音排序（伊籍 0 … 劉備 211 …），223–228 是追加的六人（祝融 孫韶 陳宮 忙牙長 楊修 劉曄，排在最後、不照五十音），229–238 是通用稱呼（客人 側室 賢者 側近 町人1–4 側近 老師；事件用，沒有人物紀錄）。

## 5. 開新遊戲：劇本資料（`$99:E436`，`rom.Rom.scenario_wram`）

`$80:8085` JSL 進載入程式，返回到 `$80:8089`（`rom.LOADER_DONE`）。`$017A` = 劇本（0 189 年、1 200 年、2 215 年），`$0184` = 玩家勢力。依序：

1. `$99:E447`：年 `$017C` = 0xBD／0xC8／0xD7（189／200／215），月 `$017E` = 0（1 月）。
2. `$99:E47D`：勢力 16 × 3 bytes（`$8C:DBCB`／`$8C:DBFB`／`$8C:DC2B`）→ WRAM `$1F4C + 4 f` = [0][君主][0][0]。
3. `$99:E4FF`：國 35 × 18 bytes（`$8C:D469`／`$8C:D6DF`／`$8C:D955`）→ WRAM `$1C92 + 20 c` 的 +0–17（+18、+19 = 0）。迴圈停在 `$1F4C`，所以最後一國（34 章安）只寫到 +17：國區塊共 698 bytes，緊接著就是勢力區塊。
4. `$80:8103`：難易度（`$03EB` = 選單項目，`$0178` = 0x88 上級／0x155 中級／0x222 初級）。上級與初級把 35 國的 金、米 換成另一張表（35 × (金, 米) LE16）：上級 `$8C:EBAF`／`$8C:ECC7`／`$8C:EDDF`、初級 `$8C:EB23`／`$8C:EC3B`／`$8C:ED53`（189／200／215）；中級沿用國紀錄的值。エディット沒有解析。
5. `$99:E55E`：人物 229 × 17 bytes（指標表 `$8C:90C2` → `$8C:90C8`／`$8C:9FFD`／`$8C:AF32`）用 MVN 搬到 `$0700 + 24 p` 的 +7–23；+0 清成 0；再依配置（229 × 5 bytes，`$8C:BE6D`／`$8C:C2E6`／`$8C:C75F`）：種類 0（仕官）→ +1 = 國 \| 0x80、+0 = 該國勢力 \| 0x80。其他種類不動（+0–6 都是 0）。

## 6. 勢力

勢力 f 只有君主一個欄位（16 × 3 bytes 的第一個；後兩個 byte 三個劇本都是 0，未解）。189 年 14 個（袁紹 袁術 王朗 孔融 公孫瓚 曹操 孫堅 陶謙 董卓 張魯 馬騰；f = 11 空；劉表 劉焉 劉備）、200 年 9 個（袁紹 曹操 李傕 張魯 馬騰 孫権 劉表 劉璋 劉備）、215 年 4 個（曹操 張魯 孫権 劉備）。君主選擇的清單（189 年：劉備 曹操 董卓 袁紹 孫堅 馬騰 劉表 袁術）是畫面上看到的，ROM 的選單表沒有解析。

## 7. 頭像（sprite 組合，48 × 64）

`$80:8968` 用人物編號 `$F9`：

1. 從 `$9B:A789 + 12 p` 取 12 個部件編號到 `$FB–$0106`。
2. 依 `rom.FACE_SLOTS` 把各部件的 4bpp 圖從 ROM 分塊複製進 `$7E:8000` 的 sprite tile 緩衝（一列 16 個 8 × 8 tile = 0x200 bytes）：部件 k 的來源 = 基底 + 編號 × 步距，再依序切成 `size` bytes 一塊放到各個緩衝位置。部件 3、5–11 的 FF = 無。部件 10 與 11 用同一個部件表（`$98:EC00`），放在臉的不同位置。緩衝 0x1000 bytes 再 DMA 到 OBJ tile（VRAM 0xC000）。
3. 畫面用 metasprite（`$81:826B` 指標表，bank `$81`；count，再 count × (dx, dy, tile, attr)），編號 = 基底 + 表情 `$0107`（`$81:8087`）：基底 0 是一般的臉（32 個 16 × 16 sprite，外側兩欄左右翻轉共用），表情 1–3 換掉 14–16 號 sprite 的 tile（眼與嘴，說話用）。夏侯惇、胡軫、張飛、文醜、陳宮（0x21、0x4A、0x91、0xB8、0xE1）有自己的 4 個 metasprite，基底 4、8、12、16、20（多 1–2 個 sprite：眼罩、鬍子等，`rom.FACE_META_BASE`）。`$4A` ≠ 0 時基底再 + 0x18（推測是畫在畫面另一側的版本）。
4. 調色盤：每人 16 色 `$9B:B2C9 + 32 p` → OBJ 調色盤 0（CGRAM 影子 `$0500`，`$80:891A`）。

武將詳細畫面上頭像在 (104, 22)（metasprite 原點 (128, 54)）。詳細畫面一直顯示 metasprite 0；1–3 只從程式碼解出（`verify_faces.py` 拍了 40 個不同時間點都是 0）。

## 8. 大地圖（mode 7）

- `$91:8000`：LZSS 串流 `$91:827D`（32768 bytes）→ `$7E:8000` → `$81:A98C` 交錯 → 交錯的 word：低 byte = 128 × 128 tilemap，高 byte = 256 個 8bpp tile（每 tile 64 bytes，一 byte 一 pixel），全圖 1024 × 1024，送 VRAM 0。平時縮成 1/4 顯示。
- 砦（`$91:8031`）：國 c 的位置 (x, y) → 基準格 tile 欄 2x − 1、列 2y − 1；國 +17 的 bit b 有設時，在 `rom.MAP_FORT_CELLS[b]`（(0, −1)、(2, −1)、(3, 1)、(2, 3)、(0, 3)、(−1, 1)）起畫 2 × 2，tile 是 `$91:8197 + 4 b` 的 4 個（左上 右上 左下 右下）。開局全部沒有砦。
- 行軍中的部隊（`$91:81AF`，人物 0–228）：+0 bit 7 = 1、bit 5–6 = 0、+1 ≠ FF 且 bit 7 = 0 時，在 tile (2 × (+1) + (+2 & 1), 2 × (+2)) 畫 2 × 2：左上 a、右上 0xE0 + 勢力（+0 低 4 bit）、左下 b、右下 c；(a, b, c) = `$91:8274`（F0 F1 F2），+0 bit 4 有設時改用 `$91:827A`（F6 F7 F8）。奇數列往右錯半格，所以部隊是走在 64 欄的六角格上。開局沒有部隊。
- 調色盤：地圖 pixel 只用顏色 0x20–0x5F（`$A0:CC8F`，64 色）；0x50–0x53、0x54–0x57 兩組各 4 色在畫面上循環（水的動畫）。只驗證了 1 月；月份會不會換調色盤沒有查。
- 國的標記是 sprite，不畫在地圖上：OBJ 1 + c 在畫面 (4x − 2, 4y − 2)，8 × 8，tile 0xC8 + (f & 7) + 0x10 × (f >> 3)、調色盤 6 + (f >> 3)、優先度 1（f = 勢力，無勢力當 15）。標記的顏色推測是該調色盤的顏色 8 + (f & 7)（189 年玩家第一個月的截圖，35 個標記中心的顏色 34 個相同，玩家的國 并州 是白色，推測和前作一樣在閃爍；標記 tile 沒有解析），OBJ 調色盤 6–7 = `$91:CFF4`（32 色；地圖畫面的 OBJ 調色盤 0、2–4、6–7 和 `$91:CF34` 起的 256 bytes 相同，1、5 有幾色不同，沒有追）。OBJ 0 是游標。`export.py` 的 `map_<年>.png` 用這個顏色畫方塊（標記 tile 的圖形沒有解析）。
- 沒有找到地形表（前作有 64 × 64 地形格；這片 ROM 裡沒有未壓縮的 4 KB 小值表，壓縮串流裡也沒認出來）。

## 11. 和前作（横山光輝 三国志）的比較

| 項目 | 前作 `yokoyama/` | 本作 |
|------|------------------|------|
| ROM | 1 MB LoROM（SlowROM，bank `$00–$1F`），Rev 0／1 | 1.5 MB LoROM FastROM（程式在 `$80–$AF`），一版 |
| 程式 | 手寫組合語言 | 同一套引擎重新組譯，位元組樣式全部不同，要重新反組譯 |
| 文字輸出 | `$00:8D60` | `$80:8C2E` |
| 字型 | `$03:8000`（16 × 16）、`$04:8800`（8 × 16） | `$9A:8000`、`$99:A000`；字形重畫、字碼重新配置，字表全部重讀 |
| 控制碼 | F1–F9 | F0–F9，對應不同（F0 武將、F1 國名、F2–F9 數字） |
| LZSS | `$01:F8FE` | `$81:A8F0`，格式相同；另有 16-byte 交錯 `$81:A98C` |
| 名表 | 224 × 8：姓、第二字（0x200 = 無）、名、讀音指標 | 239 × 8（229 人 + 10 個通用稱呼）：三個字照順序填、0x200 放最後 |
| 劇本 | 2（189、219），`$011F` | 3（189、200、215），`$017A` |
| 人物 | 14 bytes；WRAM 22 bytes（前 4 + 後 4） | 17 bytes：多了 官位、レベル（直接存）、疲労度；武器力改成 騎／弓 半 byte＋歩 一 byte；WRAM 24 bytes（前 7） |
| 配置 | 5 bytes | 格式相同 |
| 國 | 31 × 16；WRAM 21 bytes | 35 × 18（多 開発度、砦）；WRAM 20 bytes |
| 勢力 | 15 × 1（君主） | 16 × 3（君主 + 2 個 0） |
| 難易度 | 3 級；1 級 金米 × 1.6 | 上級／中級／初級：上級與初級有自己的金米表；エディット |
| 頭像 | 11 部件、共用膚色調色盤 + 每人 1 個調色盤、4 人（夏候惇 胡軫 張飛 文醜）加畫附加 metasprite | 12 部件、每人 16 色、metasprite 0–3（表情）；同樣 4 人再加陳宮改用自己的 metasprite 組 |
| 大地圖 | bank `$19` 未壓縮；城標記與城框畫進 tilemap；12 個月的調色盤 | LZSS＋交錯；國的標記是 sprite（勢力色方塊）、砦畫進 tilemap；調色盤 64 色＋水的循環 |
| 部隊 | 地形格上的格子座標 | 六角格（奇數列錯半格） |
| 地形 | 64 × 64 地形格 `$1D:D8CE` | 沒找到 |

# ヨーロッパ戦線（SFC）ROM 格式

位址是無標頭 1.5 MB HiROM 影像的檔案位移（CPU `$C0:0000` = 檔案 0；`$Cx:yyyy` → `(x << 16) | yyyy`）。
程式是 C 寫的：服務呼叫 `JSL $C0:8000`（0x17 = memcpy，經 `$00:006C` 的 MVN；0x4C = LZ 解壓到 `$7F:8000`；0x0B = VRAM 上傳），
vprintf = `$C1:286A`（格式長指標在 SP+4、va 在 SP+8），印字串 `$C1:195E(長指標)`，游標 `$C1:184A`，亂數 `$C1:3ECF(n)`。

標「推測」的是沒有用遊戲程式驗證過的解讀；標「未解」的是還不知道。各項的驗證方式見 `README.md`。

## LZ

KOEI LZ（`tools/koei_lz.py`），表區 `0x9939`，解壓程式 `$C0:9A96`；指標表 `0x14978`，650 個 3-byte 指標（entry n）。
entry 0–4、23、49、51、66–68、74、585 等不是有效串流（未用到）。

| entry | 內容 |
|-------|------|
| 5–10 | 戰場地圖 m = 0–5 的地形（1600 bytes，複製到 WRAM `$7E:40C2`） |
| 11–16 | 戰場地圖 m 的格碼（1600 bytes） |
| 17 | 戰場 metatile 池（160 × 128 bytes） |
| 87–206 | 頭像 0–119（960 bytes） |
| 207–365 | 159 筆 × 1760 bytes（55 tile），推測為圖示／圖片，未解 |
| 623 | 歐洲地圖 chr（15392 bytes = 481 tile） |

## 文字

- 半形片假名／ASCII 單 byte（cp932）。`1B 4B`（ESC K）= 片假名（每個字串開頭的預設），`1B 48`（ESC H）= 平假名；
  經歷這種多行文字，模式會延續到下一行。片假名模式中 `-` 是「ー」。選單裡半形 `[` `\` `]` 顯示為 年 月 日；兵器名的 `$` 顯示為「Ⅰ」、
  `'` 顯示為「Ⅱ」（兵器畫面截圖確認：歩兵Ⅰ／歩兵Ⅱ／装甲擲弾兵Ⅰ／装甲擲弾兵Ⅱ／近衛歩兵Ⅱ），`rom.py` 照此轉換。
- 2-byte 碼 c → 字形：`$C1:19C0`。c ≤ 0x8460：字形 g = c − 0x8140；0x8460 < c < 0x89F0：畫字形 0；c ≥ 0x89F0：先換成
  `0x8200 + ((c − 0x89F0) << 8)`（16 位元）。來源位址 = `$CA:(0x9000 + 32 (c' − 0x8140))`，位移只取 16 位元（`rom.glyph_address`）。
  經歷裡有 `0x9140` → 字形 192「降」。
- 字型：`0xA9000 + 32 g`，16×16 1bpp，四個 8×8（左上、右上、左下、右下），652 字，JIS X 0208 順序的漢字子集（第一水準，最後 651 = 擲）。
  字形 → 字元：用系統日文字型依 JIS 順序比對再人工修正（`data/charset.txt`）。`0xA8000` 起是 128 個半形 8×16 字形（排列不是 ASCII 順序，未解）。

## 劇本

選單字串 `0x69CE4`（6 個長指標，如 `1 フランス侵攻戦  1940[ 5\10]`）。選劇本並確認後，`$C6:06xx` 用服務 0x17 把該劇本區塊（0x1FEB bytes）
複製到 WRAM `$7E:2000`。之後遊戲會在複本裡填入 WRAM 指標（約 310 bytes，部隊串列等），所以比對要在 MVN 剛結束時做。

| 劇本 | 區塊 | 地圖 | 日期 | 將領（枢軸＋連合） | 都市 |
|------|------|------|------|------|------|
| 1 フランス侵攻戦 | `0x1513C` | 0 | 1940/5/10 | 10 + 10 | 11 |
| 2 北アフリカ戦 | `0x17127` | 1 | 1942/5/26 | 12 + 12 | 15 |
| 3 クルスク機甲戦 | `0x19112` | 2 | 1943/7/5 | 12 + 12 | 13 |
| 4 ノルマンディーの戦い | `0x1B0FD` | 3 | 1944/6/6 | 12 + 12 | 20 |
| 5 バルジの戦い | `0x292EB` | 4 | 1944/12/16 | 12 + 12 | 21 |
| 6 ベルリン攻防戦 | `0x2B2D6` | 5 | 1945/4/16 | 9 + 12 | 14 |

區塊：+0 = 0x45，+1 地圖號，+2 年 − 1940，+3 月，+4 日，+5 調色盤選擇（`$C1:0893`，全部 0），+0x1E 推測為玩家陣營（城市畫面拿它和都市
+57 的陣營比，`$CA:1269`），其餘 header 未解。

### 將領表（區塊 +0x220，WRAM `$7E:2220`）

40 槽 × 22 bytes：0–19 枢軸、20–39 連合；+9 = FF 是空槽。

| 位移 | 內容 |
|------|------|
| +0 | 名字 9 bytes（半形片假名，0 / 空白補；最多 8 字，長名被截，如「ラフェンシュタイ」） |
| +9 | 國籍 bit：01 ドイツ 02 イタリア 04 アメリカ 08 イギリス 10 フランス 20 ソ連（名稱取自畫面國旗） |
| +10 | 指揮 |
| +11 | 魅力 |
| +12 | 未解（1 人模式枢軸固定寫 99） |
| +13、+14 | 未解（相同值） |
| +15 / +16 / +17 | 歩兵 / 砲兵 / 戦車 |
| +18 | 経験（開局 0） |
| +19 | 未解 |
| +20 | 人物 id（0–93；頭像與經歷都用它） |
| +21 | 未解（將領 0；領袖 04 / 05，推測元首／參謀長） |

同一 id 在各劇本的記錄相同。顯示：能力審查畫面 `$CA:2883` 起，vprintf `$CA:6472` 印 指揮 魅力 経験（+10 +11 +18）、`$CA:6486` 印 歩兵 砲兵 戦車。
1 人模式開局會重擲：`$C6:1040` 起以 WRAM `$55B8`（區塊將領表原樣）為底，`$C1:01F9(base)`：base + rand(41)，再 rand(10) ≠ 0 時 −20，
否則上限 99（由反組譯）；寫 +10 +11 +12（id < 40 則 99）、+13 = +14、+15 +16 +17。

### 領袖 `0x1D218`

6 筆，將領格式（名字空白補）：ヒトラー(94) ハルダー(95) アイゼンハワー(96) スミス(97) スターリン(98) ワシレフスキー(99)。+19 = FF。

### 經歷 `0x6C8E5`

94 × 7 個長指標（`$C6:C8E5`），人物 id p 第 k 行 = 第 7p + k 個；文字在 `0x6D09B` 起。審查畫面逐行用 `$C1:195E` 印。
id ≥ 94 沒有經歷（表之後就是經歷文字）。

### 都市（區塊 +0x1B28，WRAM `$7E:3B28`）

58 bytes 一筆，到名字為空或區塊結尾（最多 21 筆）。都市畫面 `$CA:11F2` 起：清單（`$7E:7FD1`，3-byte 指標）只收玩家陣營的都市。

| 位移 | 內容 |
|------|------|
| +0 | 名字 11 bytes |
| +11 / +12 | x / y（戰場格；全部 94 筆都落在地形「都市」格） |
| +13 / +15 / +17 | 弾薬 / 燃料 / 食料（LE16；都市畫面 `$CA:6363` "%5d   %5d   %5d" 印的就是這三個。名稱依畫面圖示與 `0x7D017` 的標籤 "弾薬 %5d 燃料 %5d 食料 %5d"、`0x1E0F7` 的名稱表） |
| +19 / +21 / +23 | 同樣三項的第二組（ROM 裡全部和第一組相同；畫面不印，推測上限或初期值，未解） |
| +25 / +26 | 耐久 現在 / 上限（`$CA:635B` "%2d/%2d"） |
| +27 | 駐軍 6 槽 × 5 bytes：兵器 id（FF 空）、數量 LE16、2 bytes 未解。詳細畫面只列前 3 槽（兵器名 + `$CA:6332` / `$CA:6336` 數量） |
| +57 | 旗標：bit 4 = 陣營（1 連合、0 枢軸；`$C3:0694`）；bit 6 都市畫面 `$CA:12AB` 會測（意義未解）；低 4 位元未解 |

## 兵器 `0x1D2BC`

158 筆 × 14 bytes。兵器畫面 `$CA:24A0`：每列從清單（WRAM `$7E:805A` 起，DP `$0C` 指著）讀 1 byte 索引（`$CA:24D0`），記錄 = `$C1:D2BC + 14 idx`，
名字用 `$C1:195E`，數值用 `$CA:6433` "%2d %2d %2d %2d %2d"，參數為 +7 +6 +8 +9 +12（畫面欄 AP AT 防 速 射）；國旗依 +3。

+0 名字長指標、+3 國籍 bit、+4 登場時期（推測：高 4 位 = 年 − 1940、低 4 位 = 月，0 = 開戰時）、+5 種別（推測：0 歩兵 1 自動車化歩兵 2 装甲歩兵
3 戦車・自走砲 4 砲・対戦車砲 5 工兵 6 修理兵 7 補給兵，依各類兵器名歸納）、+6 AT、+7 AP、+8 防、+9 速、+10 +11 未解（推測燃料／補給相關）、
+12 射、+13 未解。

## 頭像

LZ entry 87 + 人物 id（`$C2:0664`），120 張，40×48（5×6 個 4bpp tile 逐列，960 bytes）。沒有組合臉、沒有頭像碼。
審查畫面把頭像放在 VRAM byte 0xEC00，用 CGRAM 調色盤 11（OBJ 3），ROM 來源 `0x1E887`。id 100–119 沒有對應人物。

## 歐洲地圖（標題／劇本選單背景）

BG2（mode 1，8×8 tile）。tilemap：`0x68EFE` 起 30×23 個 LE16（含調色盤 2 bit），放在畫面 tile (1, 2)；chr：LZ entry 623 載到 tile 0x20
（VRAM byte 0x8400）；CGRAM 調色盤 2 在 `0x69B62` 和 `0x69B82` 兩組間輪替（第 1–4 色互換，海面動畫），匯出用第一組。

## 戰場地圖

每張 40×40 格、每格 16×16 px，BG2（mode 1，16×16 tile；tilemap 64×64 在 VRAM byte 0x2000，四象限 32×32，地圖在 (1,1) 起、外框 tile 0x112C；
chr 在 VRAM byte 0x8000）。載入 `$C6:09F7` 起：

- 格碼 = LZ entry 11 + m；tilemap 詞 = `0x1E10F + 0x110 m + 2 × 格碼`（`$C6:0AA8`，經 WRAM `$7E:489A` 一列緩衝）。
- 地形 = LZ entry 5 + m，原樣複製到 WRAM `$7E:40C2`；低 4 位元 = 地形號，`$C3:1B16(x, y)` 讀它，名字表 `$C1:E017`：
  0 進入不可 1 都市 2 道路 3 平地 4 砂漠 5 川 6 湿地 7 荒地 8 森林 9 丘陵 10 橋。高 4 位元：ROM 裡 0 或 8，執行時會加 1、2（未解，推測佔領／部隊）。
- tile：metatile 池 LZ entry 17（每個 128 bytes：上半 64 bytes → tile t、t+1，下半 → t+16、t+17）；每圖的使用清單 `0x6897F + 0x8C m`
  （LE16，低 byte FF 結束，最多 70），第 p 項放到 t：從 2 起每次 +2，t 到 16 的倍數時再 +16（`$C6:05A0`）。
- 調色盤：CGRAM 調色盤 2 = `0x146AC + 64 s`（地圖 4 用 `0x147EC + 64 s`），s = `0x1492C` 的 LE16 表 [區塊 +5]（全部劇本 s = 3 →
  `0x1476C`、地圖 4 `0x148AC`）。地圖畫面上遊戲把這組與它後面 32 bytes 的一組分別放在 WRAM `$7E:0D77` / `$7E:0D97`，每 20 幀輪流 DMA 到
  調色盤 2（兩組只差第 8、13 色，是閃爍），所以截圖時看到哪一組取決於時間點。匯出用第一組。
- 執行時會變的格：佔領都市、架橋／爆破（都市／橋／川格的 tile 會換），驗證時各圖 0–11 格不同，全在這些地形上。

## 操作序列（tools/drive.py 語法；`scenes.py`）

- 標題約 4200 幀；`w4600 start:10 w200 a:10 w300` → 模式／劇本清單（游標在キャンペーンモード；down 一次 = 劇本 1）。
- 劇本 k：`down:10 w60` × k、`a:10 w300`（說明）、`a:10 w300`（これで良いですか Y，此時複製區塊）。
- 0 人模式：`a:10 w300 a:10 w300 a:10 w300 a:10 w600 a:10 w600` → 戰場（電腦對打）。
- 1 人枢軸：`down:10 w60 a:10 w300 a:10 w300 a:10 w300 a:10 w300` → 将軍の能力を検討せよ（a 重擲、b 下一位；頁間要等約 300 幀，否則會漏頁）。
  再 `b:10 w100`×10 + `b:10 w600` → 貴官の分身を決定せよ → `a:10 w300` + (`down:10 w60 a:10 w300`)×6 → 組織圖 Y → `a:10` × 11 過訊息到指令畫面
  （約第 17300 幀，`TO_COMMAND`）。連合軍：枢軸／連合那一步前加 `down:10 w60`（`TO_COMMAND_ALLIES`）。
- 指令選單 2 欄（戦術 移動／情報 編成／要請 空軍／特命 待機），選單移動用 `down:4`。情報：将軍 部隊／兵器 都市／条件 → 自軍／敵軍。
  兵器：`down:4 w30 a:10 w200 down:4 w30 a:10 w200 a:10 w300`；都市：`down:4 w30 a:10 w200 down:4 w30 right:4 w30 a:10 w200 a:10 w300`，再 a 看第一個都市的駐軍。

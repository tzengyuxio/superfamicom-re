# SFC エアーマネージメントII 航空王をめざせ ROM 格式

位址寫法：`$BB:AAAA` 是 CPU 位址（LoROM），「ROM 0x……」是去掉 header 後的檔案偏移，`lorom(bank, addr) = (bank & 0x7F) × 0x8000 + (addr & 0x7FFF)`。WRAM 位址 `$xxxx` 都在 `$7E`。

## 1. 硬體與引擎

- 1 MB LoROM，無 header。程式是 C 編譯出來的原生 65816 程式（bank `$80–$8C`，ROM `0x00000–0x67FFF`），**不是**前作的 KOEI p-code。部分函式在 `$04`／`$06` 等 bank 跑、部分在 `$84`／`$86` 鏡像跑，Mesen 的 exec hook 兩邊都要掛（例：頭像繪製 `$04:8199` 與 `$84:8199`）。
- 文字輸出都走服務分派器 `$00:8000`（`JSL` 前把服務號壓在堆疊）：3C／43／4F／61 是 printf 類（va 指標在 S+6），55 是 sprintf（S+10）。格式字串和參數都在記憶體裡，驗證腳本就是 hook 這裡記錄遊戲自己印的字（`tools/am2.py` 的 `PRT_LUA`）。
- 字串多為半形片假名（cp932 單 byte），由遊戲印出時轉成全形。`rom.half_to_full` 做同樣的轉換：NFKC、ASCII → 全形、`ー` → `－`（遊戲字型用 `－` 當長音）。

## 2. 檔案表（ROM `0x6000`）

16 bytes 一筆：名稱 8 bytes、bank LE16、位址 LE16、大小 LE32；名稱第一 byte = 0 結束。共 196 個檔（`output/files.csv`）。很多是 KOEI LZ（共用 `tools/koei_lz.py`），例如 `MAINMAP`、`AREA1`、`AREAMAP`、`TOUSHI`、`INFOSALE`。

本專案用到的檔：

| 檔 | 內容 |
|----|------|
| `FONT` | 字型（§3） |
| `SECRET`／`STAFF`／`MAKER`／`MAYOR` | 頭像 7／11／6／5 張（§8） |
| `FACEPAL` | 頭像調色盤 30 組 × 16 色 |
| `MAPBACK` | 世界地圖的海（BG2）：調色盤 32 bytes、tilemap 32 × 22 words、tile |
| `MAINMAP`（LZ） | 世界地圖的陸地（BG1）：480 個 4bpp tile，依序排在第 3–17 列 |
| `M_COLOR` | 陸地調色盤 |
| `AREA1`（LZ × 7） | 7 個地區地圖，每個是一條 LZ 串流（檔內偏移 `0x0000 0x23D1 0x466A 0x7041 0x8BCF 0xA3ED 0xC62B`）：調色盤 32 bytes + 736 個 4bpp tile |
| `AR_MAP` | 地區地圖共用的 tilemap 32 × 23 words（tile 0..735、調色盤 1） |

`AREA4` 是地區 3 串流的副本；`AREAMAP`、`WOLDBASE` 等其餘檔的用途未解。

## 3. 字型與文字編碼

字形查詢 `$00:B8DE`：輸入 Shift-JIS 碼（`$4C`），輸出種類（`$98`）與編號（`$9A`）。

| 碼範圍 | 字 | 種類 | 字形 |
|--------|----|------|------|
| `< 0x824F` | 記號 21 個（`$00:BEE8` = ROM `0x3EE8` 的 LE16 碼表；不在表內 → 編號 1 ■） | 2（8×16） | tile `0x160 + 2i` |
| `0x824F–0x8258` | 數字 | 2 | tile `0x18A + 2i` |
| `0x8260–0x8279`、`0x8281–0x829A` | 英文字母 | 2 | tile `0x19E + 2i` |
| `0x829F–0x82F1` | 平假名 83 | 0（16×16 1bpp） | `FONT + 0x18D0 + 32i` |
| `0x8340–0x8396`（跳過 0x837F） | 片假名 86 | 2 | tile `0x1D2 + 2i` |
| 其他 | 漢字 461 個（`$00:BF12` = ROM `0x3F12` 的碼表）；不在表內 → ■ | 0 | `FONT + 0x18D0 + 0xA60 + 32i` |

- 8×16 字形是 `FONT[0:0x18D0]` 的 2bpp tile，開機時載到 VRAM `$CF30`（tile `0xF3` 起），一個字用上下兩個 tile。
- 16×16 字形每 byte 由 `$00:B9DF` 前的迴圈複製兩次成 2bpp 到 WRAM `$0CE9`。
- 碼與字形對照：`data/charset.tsv`（713 字）；漢字依字形順序：`data/kanji.txt`。有幾個碼畫出來的字和 Shift-JIS 不同：`8197`→万、`8194`→㎞、`8160`→↔、`8183`→◁、`8184`→▷、`818F`→人、`8181`→便、`8390`／`8391`→■、`88BC`（鮎）→々。小寫 `ａ–ｚ` 和大寫共用字形（同一個 tile），畫面上一律是大寫，例如製造商 `ｂａｅ` 顯示成 BAE。

## 5. 劇本與開局狀態

4 劇本：1955／1970／1985／2000 年開始（選單的年份範圍 1955–1975 等）。開局由 `$82:B42C` 建立：

- `$24E9` = 劇本編號。
- 都市記錄 `$2CBD`（89 × 4）與 `$3E37`（89 × 2）：劇本 1／4 直接複製 A／B 表；劇本 2、3 的 byte 0 取 B，byte 1–3 與第二記錄 byte 0 由 `$82:B6AC` 插值：`a + trunc((b − a) × s / 3)`，夾在 0..255（s = 劇本編號 0–3）。`$3E37` 第二 byte 為 0。
  - `$2CBD` byte 0 = 國家（驗證：國家代表視窗印出的國名）。byte 1–3 意義未解（**推測**：依數值型態可能是人口規模、觀光、經濟）。`$3E37` byte 0 未解（推測與機場容量有關）。
- 再從 bank `$05` memcpy：`$05:E7DA → $2E21`（57）、`$05:EF59 → $2955`（192）、`$05:F019 → $2AD5`（228）、`$05:F3C5 → $3DF7`（64），內容未解（`output/init_tables.csv` 只列原始 bytes）。
- 世界事件（§5.1）中年份早於起始年的，開局時就套用（`$0A:EA13`）。

### 5.1 世界事件（`$0A:FDC2`，8 bytes × 55）

year LE16、quarter LE16、message、target、type、value；year 不在 1951–2029 就結束。

- type 0：都市 `target` 的國家改為 `value`（例：1956 チュニス → チュニジア）。
- type 1：`$2E21[target]` = `value`（國家表的值，意義未解）。
- message = 255 表示和前一筆一起顯示；quarter 與 message 的確切意義未解。

## 6. 機種（53 × 11 bytes）

| byte | 內容 |
|------|------|
| 0 | 製造商 |
| 1 | 座席數 / 10 |
| 2–3 | 航續距離 km |
| 4–5 | 基準價格（万$） |
| 6 | 生產開始年 − 1900 |
| 7 | 生產終了年 − 1900（200 = 不停產）——**推測**，畫面未顯示 |
| 8 | 100 − 燃費 |
| 9 | 100 − 整備性 |
| 10 | 旗標（未解） |

發注畫面顯示的價格依玩家和製造商的關係變動（`$04:B7D3`）：基準 × k / 100，k = 90／100／110，有時再減 10（所以也出現 80）；製造商不賣時是 65535。何時用哪個 k 未完全解開。

## 7. 地圖

- **世界地圖**（256 × 176）：BG2 是 `MAPBACK`（tilemap 在 VRAM `$F000`、tile 在 `$6C00` = tile `0x160` 起、CGRAM 第 2 列）；BG1 是 `MAINMAP` 的 480 tile 直接依序排在 tilemap `$E800` 第 3–17 列、調色盤 1 = `M_COLOR`、顏色 0 透明。
- **地區地圖**（256 × 184，7 張）：BG tilemap `$F000` = `AR_MAP`（32 × 23，7 地區共用），CHR `$4000` = 該地區 `AREA1` 串流的 tile，CGRAM 第 1 列 = 串流前 32 bytes。都市以 sprite 畫在 `$05:E2E5` 的位置。
- **戰術地圖**：本作沒有戰鬥，不適用。

## 8. 頭像

- 40 × 48 = 5 × 6 個 4bpp tile（row-major），960 bytes 一張，原樣複製到 VRAM。調色盤是 `FACEPAL` 第 n 組（顏色 0 透明），載入 CGRAM 第 4 列。
- 遊戲用 4-byte 描述畫頭像（`$04:8000`／`$04:8199`）：kind LE16（0 SECRET、1 STAFF、2 MAKER、3 MAYOR）、image、palette。SECRET／STAFF 畫到 VRAM `$0000`，MAKER／MAYOR 畫到 `$0800`（訊息窗）。
- **秘書**（`$82:AF85`，存在 `$28C5`）：image = 0..6 隨機，palette = 本社地區基準 + 0..3 隨機。**職員**（`$82:B0A0`，`$28D5`）：每人 4 名，image 0..7 互不重複，palette 同上。地區基準：歐洲／大洋洲／北美 26、非洲 8、中東／南美 12、東南亞 16。
- **國家代表**（`MAYOR` 檔，`$8C:8634`，視窗印「％ｓ代表」）：image = 國家 % 5，palette = 都市地區（歐洲／大洋洲／北美 0、非洲 1、中東／南美 2、東南亞 3）。
- **製造商**：固定描述 `$05:EEC7`，12 家用 6 張圖（多家共用一張、調色盤不同）。
- 沒有內部的單一頭像碼，所以 kaodata 的 portrait 不寫 `code`。

## 9. 操作序列（驗證用，幀數從開機算）

`tools/am2.py`：標題 → NEW GAME → 劇本選單（約 3100 幀）→ 劇本 + YES（約 3397 幀建好開局狀態）→ 難易度 → 玩家數 → 地區選單（約 4280）→ 本社都市（約 4355）→ 確認 → 設定畫面 → 開始。之後 COM 玩家回合結束停在世界地圖，按 A 開始玩家回合，秘書第一則訊息在約 7963 幀畫頭像（savestate 7900）。再 8 則訊息到主畫面，右 ×4 → 航空機発注 → 第一家製造商（劇本 1 是ビッカ－ス），規格畫面約 10808 幀印出 `$3DC0` 的機種記錄（savestate 10790）。

## 10. 未解

- 都市記錄 `$2CBD` byte 1–3、`$3E37` byte 0 的意義（數值已和 ROM 逐 byte 對上，只是不知道是什麼）。
- `$2E21`（國家表，值 0–4）、`$2955`、`$2AD5`、`$3DF7` 的內容；`$05:E815`、`$05:EEBC`。
- 世界事件的 quarter、message 欄。
- 機種 byte 10 旗標；生產終了年（推測）；價格係數 k 的選擇規則。
- 關聯事業名稱未在畫面驗證，事業 → 類別對應未解。
- `$05:E233` 世界座標沒有獨立的 Mesen 驗證。
- `AREAMAP`、`WOLDBASE`、`TOUSHI`、`INFOSALE` 等多數檔的用途；投資、廣告、服務等經營參數表。

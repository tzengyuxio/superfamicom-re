# SFC 項劉記 ROM 格式

KOEI，SFC。檔案 `roms/Kouryuuki (Japan).zip`。

本文的偏移一律是**檔案偏移**（無 copier header 的 1.5 MB 映像）。CPU 位址寫成 `$bb:aaaa`，HiROM：檔案偏移 = `位址 & 0x3FFFFF`（`$C0:0000` = 檔案 0）。

## 1. 硬體與引擎

| 項目 | 內容 |
|------|------|
| 標頭（`0xFFC0`） | `kouryuuki`，map mode `31`（HiROM、FastROM），型別 `02`（ROM＋RAM＋電池），SRAM 8 KB |
| 向量 | native NMI `$00:84A2`、IRQ `$973A`；emulation RESET `$8009` |
| 引擎 | 和スーパー三國志II 一樣是 p-code 直譯器，資料讀取的 PC 都是 `$00:006F` |
| 操作 | 標題 → START → START → 新しくゲームを始める（a）→ 劇本（↓ 選）→ 開場動畫約 6500 幀無法跳過 → 設定畫面 a × 3 → 君主（只有項羽、劉邦可選，→ 切到劉邦）→ a 開啟君主簡介 |

Mesen 的 savestate 只能在 exec callback 裡建立／載入，驗證腳本都掛在 NMI handler `$00:84A2` 上。

## 2. 壓縮資料（`0x9E0E5`）

727 個 3-byte 長指標，指向壓縮串流，由 `$C0:A2AB` 解壓（`rom.decompress`）。演算法和表與天翔記的 `$C0:F194` 相同（見 `tenshouki/docs/ROM_FORMAT.md` §2），表在 bank `$C0`：`0xA14E`（length 值）、`0xA18E`（length 位元數）、`0xA1CD`（length shift）、`0xA1D5`／`0xA295`（近距離）、`0xA29E`／`0xA2A3`（遠距離）。entry 0 不是串流。

| entry | 內容 |
|-------|------|
| 1 | 大地圖 55 × 44 格：0 = 道路，1 = 其他（§8） |
| 2 | 大地圖 55 × 44 格：地物號 0–48（§8） |
| 3–8、11–16 | 開局時解壓的地圖用圖，未解 |
| 21–117 | 頭像 F00–F96（§7） |
| 343–365、453–465、480 | 開局時解壓的地圖用圖，未解 |

## 3. 字型與文字

**字型**：16 × 16 1bpp，每字 32 bytes，由 4 個 8 × 8 tile 組成（左上、右上、左下、右下，每列 1 byte）。字 0–1023 在 `0x0000`，字 1024–1287 在 `0x17DF00`。

**文字碼**：2-byte 碼 `0x8140 + 字號`（大端）。順序是 JIS X 0208 的子集：

| 字號 | 內容 |
|------|------|
| 0–58 | 符號、全形數字與英文 |
| 59–138 | 平假名 |
| 139–218 | 片假名 |
| 219–約 1215 | 第一水準漢字 |
| 約 1216–1268 | 第二水準漢字 |
| 1269–1284 | 追加的人名、地名用字（蒯 翟 淄 碭 眙 酈 噲 芮 卬 靳 滎 陘 邾 睢 盱） |
| 1285–1287 | 實心方塊 |

字號 → 字的對照在 `data/charset.txt`：把每個字形和系統字型（ヒラギノ、BIZ UDゴシック）依 JIS 順序做 DP 對齊，再用人名讀音與 `tools/charset_sheet.py` 的對照圖目視修正。1216、1220、1233、1249、1266、1270 仍不太確定。

控制碼：`0A` 換行、`09` 縮排、`1B 'C' n` 換色、`00` 結束。半形片假名與 ASCII 是 cp932 單 byte。

## 4. 劇本

4 個，選單文字在 `0x9DFCD`：

| # | 年 | 標題 |
|---|----|------|
| 1 | 前 206 | 漢中王即位す |
| 2 | 前 205 | 項 義帝を弑す |
| 3 | 前 204 | 劉 項 広武に対す |
| 4 | 前 203 | 項 楚歌に涙す |

**劇本狀態** = WRAM `$7E:2000–$7E:472C`（`0x272D` bytes），由 ROM 的幾段直接複製組成（`SCENARIO_PIECES`）：

| 劇本 | 片段（WRAM 位址 ← 檔案偏移，長度） |
|------|------|
| 1 | `$2000` ← `0x16F8B`，`0x12F8`；`$32F8` ← `0x4D6E3`，`0x398`；`$3690` ← `0x18283`，`0x57C`；`$3C0C` ← `0x7D5AC`，`0xA71`；`$467D` ← `0x187FF`，`0xB0` |
| 2 | `$2000` ← `0x3D172`，`0x12F8`；`$32F8` ← `0x6E1EC`，`0x398`；`$3690` ← `0x188AF`，`0x109D` |
| 3 | `$2000` ← `0x1994C`，`0x272D` |
| 4 | `$2000` ← `0x1C079`，`0x272D` |

`$2000–$32F7` 的內容未解（推測是勢力、外交關係等）。

## 5. 人物（92 人，編號 0–91）

### 5.1 姓名（`0x1668A`，17 bytes）

| 偏移 | 內容 |
|------|------|
| 0–5 | 姓名，3 個文字碼，不足補 0 |
| 6 | 0 |
| 7–14 | 讀音，半形片假名，補 0 |
| 15 | 前 206 年的年齡（生年 = 前 206 + 值；年齡 = 生年 − 劇本年） |
| 16 | 未知 |

人物簡介只有項羽、劉邦兩人：`0x9D939` 兩個長指標，指向文字。

### 5.2 劇本人物（WRAM `$32F8`，92 × 10 bytes）

| 偏移 | 內容 |
|------|------|
| 0 | bit 4–7 勢力；bit 0–3 旗標：0 君主、1 武将、2 未知（例：楼煩）、7 在劇本 3、4 有 24 人（推測已死亡）；bit 3 推測是文官 |
| 1 | 外交，`"DCBA"[值 // 2]` |
| 2 | 所屬軍（軍隊編號） |
| 3、4 | 体力、体力上限 |
| 5、6、7 | 戦闘、統率、用兵 |
| 8 | 経験 |
| 9 | 未知 |

某勢力的君主 = 該勢力旗標 `& 7 == 0` 的人。劇本 1 有 16 個勢力（張耳的旗標是 8）。

## 7. 頭像

40 × 48 = 5 × 6 個 4bpp tile，逐列排列，960 bytes。人物 n 的頭像是 entry `21 + n`（`$C9:4341`，指標 `$C9:E124 + 3n`）。共 97 張（F00–F96），人物用到 F00–F91；F92–F96 屬於誰未知。

所有頭像共用一組 16 色調色盤 `0x9E9EA`（BGR555），由 `$C2:28E0` 載入 CGRAM 調色盤 8（sprite 調色盤 0）。君主簡介畫面把頭像放在 VRAM byte `0x400`。

## 8. 大地圖

55 × 44 格，每格畫成 4 × 4 個 BG tile（`$C2:0E8C`，編譯過的 C 程式，會除以 55）。entry 1 標出道路格，entry 2 是每格的地物號 0–48；地物號與 tile 的對應和渲染程式都還沒解開。

回合畫面：BG2（tilemap VRAM word `0x7800`，調色盤 3、4）是地形，BG1（`0x7400`，調色盤 5）是疊加層，character base 是 word `0x4000`。WRAM `$5420` 是畫面 tilemap 的緩衝。

`output/map_places.png` 只畫格子：道路、有地物號的格，以及 39 個地點的位置。

# SFC 三国志正史 天舞スピリッツ ROM 格式

檔案 `_original/sfc/Sangokushi Seishi - Tenbu Spirits (Japan).zip`（只有一版）。不是光榮的作品：標題畫面顯示「© WOLF TEAM © TELENET JAPAN」，標頭 maker code `A0`。ROM 裡沒有找到年份字串，本文不寫發售年。

本文的位址寫成 CPU 位址 `$bb:aaaa`（程式在 `$00–$3F` bank 執行，SlowROM），LoROM：檔案偏移 = `bb × 0x8000 + (aaaa − 0x8000)`；WRAM 寫成 `$7E:xxxx`／`$7F:xxxx`。標記：

- **已驗證**：有 `verify_*.py` 在 Mesen 2 裡跑遊戲本身的程式比對（腳本名寫在各節）
- **已核對（Mesen 人工）**：在 Mesen 裡對照過畫面或程式行為，沒有寫成腳本
- **推測**：只從資料分佈或命名推論，沒有獨立驗證
- **未解**：意義不明，匯出時只輸出原始值

|------|------|
| SHA-1（.sfc） | `bcb8d5dc750f28a677cf55c727c9e98f95571be3` |
| 大小 | 1572864 bytes（1.5 MB），無 copier header |

## 1. 引擎與操作

| 項目 | 內容 |
|------|------|
| 指標介面 | 整個遊戲用游標（滑鼠式）操作。游標是 OAM sprite 0：`$7E:0200` = X、`$0201` = Y（OAM 影子，每幀 DMA）。B = 點選／確定，A = 取消／關窗。點選判定 `$00:980E`：桌面座標 x = `$0200` − 4 + `$0B93`，y = `$0201` + `$0B91`（`$0B93`／`$0B91` 是桌面捲動）。Mesen 截圖的 y = 游標 y + 7 |
| 寫游標 | 標題、選單畫面直接寫 `$0200`／`$0201` 再按 B 即可；下拉選單內寫完游標要先用十字鍵推一下（`right:4 left:4 down:4 up:4`）B 才會生效（選單另有追蹤變數，如 `$0C33` = y + 8）。選單內游標每幀移 1 px |
| 桌面捲動 | 游標推到畫面邊緣會捲動桌面（往下最多約 `$0B91` = 0x40；往右實測到 `$0B93` = 0x38 左右就停）。Y + 十字鍵也會移動游標／捲動，但行為不穩定。直接寫 `$0B91`／`$0B93` 畫面會捲，但 BG2 的軟體畫面不會重畫 |
| 時間 | 地圖預設暫停；圖示 3（停止標誌）解除 |
| NMI | 開機標誌之後（第 362 幀）`$4200` 寫成 01，NMI 關掉，改在 `$00:AD96` 輪詢 `$4212` 等 vblank（RTS 在 `$00:ADA2`）；進主地圖時 `$4200` = B1，NMI 重新打開，`$00:AD96` 不再被呼叫。所以 savestate 在選單畫面要掛 `$00:ADA2`，在主地圖要掛 NMI handler（`tools/replay.py` 的預設） |
| 畫面 | 地圖與視窗：mode 1。BG1 tilemap byte 0x5000（64×64，視窗框，chr 0），BG2 tilemap byte 0x7000 是軟體畫面（每格一個獨立 tile，chr byte 0x8000），地圖與視窗文字都畫進去；VRAM 寫入清單從 `$7E:6000` DMA（mode 4 到 `$2116`） |
| 腳本 | `$00:E336` 疑似腳本直譯器（bank `$21` 的資料由它讀），未解 |
| 程式 | 文字、地圖、頭像的程式在 bank `$00` 與 `$21` |

### 開機到主地圖（`p:x:y` = 寫游標後等 4 幀；按鍵按住 10 幀後放 20 幀）

```
w440 start:10 w300 start:10 w500 start:10 w500 w30 p:90:128 b:10 w300 p:128:82 b:10 w300 w100
p:118:212 b:10 w300 w300 p:197:120 b:10 w300 p:120:186 b:10 w300 p:128:137 b:10 w300 p:121:160 b:10 w300 w600
```

標題（PUSH ANY BUTTON）→「ゲームを始めます」新規（游標 (90,128)）→ 劇本清單（列在游標 y 82／105／128／156：シナリオ1 190年 後漢戦国、2 200年 龍虎激突、3 215年 天下三分、4 227年 武侯出師）→ 開場文字（了 (118,212)、否 (128,212)）→「諸侯を選択して下さい」（中国全土図＋右側君主清單，一列一個勢力，依勢力順序；(197,120) 是第 2 列 劉虞）→ 君主卡（了 (120,186)）→ 難易度 易／普／難（普 (128,137)）→ 確認（了 (121,160)）→ 主地圖「190年4月1日」。

劇本載入程式 `$00:CA31` 在這段會跑三次：開場文字按「了」之後（不是點劇本的當下）、點君主時（君主卡用的就是這次載入的資料）、開始遊戲時。

### 主選單

| 圖示 | 內容 |
|------|------|
| 1 (16,12) | 記録 読込 終了 官職 戦闘 |
| 2 (32,12) | 中国全土図（y≈31）、地域拡大図、郡国情報検索（y≈64）、武将情報検索（y≈80）、年月日 |

武将情報検索：清單視窗 州名 → 郡国名 → 勢力名 → 武将名，分頁 政 外 策 采 武 徳 年。點郡国列出所在（+29）是該郡国、且在場（§4.1 +14、+30）的人物，依人物編號，名字由 `$00:CB6E` 畫（X = 人物紀錄位址）；點武将名開武將詳細視窗（讀音、姓名、頭像、勢 城 血 官，右欄 政～年）。詳細視窗開在點選位置附近，點在右側時右欄會超出可捲動的桌面範圍而看不到。

郡国視窗：在地圖上點城（或在郡国情報検索點郡国名）開啟，同樣開在點選位置附近；視窗很寬，只有點在地圖視窗最左邊的城才完整落在桌面內（`verify_provinces.py` 用劉虞開局、地圖往左捲一格後的 代）。內容見 §4.3。

地圖視窗的捲動：捲軸滑塊兩端的箭頭（劉虞以外的開局位置不同；勢力 0 開局時 ◀ (149,213)、▶ (166,214)、▲ (239,100)、▼ (236,104)）每點一次捲 1 格（16 px），按住連續捲，直到滑塊離開游標。視野左上角記在 `$7F:29D8`（128 y + x，格），直接寫它不會重畫。

## 2. LZSS（**已驗證**：`verify_lz.py`，4 劇本各從開機玩到主地圖，解壓程式的 28 次呼叫、22 個串流的 WMDATA 輸出全部和 `rom.lz` 相同）

`$00:A527`：A = bank、Y = 位址，輸出寫 WMDATA `$2180`（呼叫前設好 `$2181–$2183`）。

| 位置 | 內容 |
|------|------|
| +0 | LE32 壓縮長度（不含 8 byte 標頭） |
| +4 | LE32 輸出大小 |
| +8 | 資料：flag byte（低位元先），1 = literal 一 byte；0 = 兩 byte lo、hi：位置 lo \| (hi & 0xF0) << 4，長度 (hi & 15) + 3 |

環狀緩衝 4096 bytes（`$7E:0EA7`），r 從 0xFEE 開始，預先填入：0–255 各 13 個、0..255、255..0、128 個 0、0x6E 個空白。串流可以跨 bank（LoROM 檔案偏移連續）；下一個串流緊接在 +8 + 壓縮長度（`$00:CA13`）。掃描 ROM 找到 139 個合法串流；已知用途：劇本 12 個（§4）、中国全土図 tile `$24:94CD`（§8）、bank `$0B` 的 10 個（第 2275 幀點劇本時解 `$0B:A0BA`，推測是開場文字／腳本，未解）。其餘（0xA0000–0xB8B8E 36 × 4928、0xB96ED 起 5 × 7072、0xFF16F 起 7 × 6144、0x10336B 起 19 × 3840 等）未解。

## 3. 文字與字型

文字是 Shift-JIS，每字 2 byte（高位 byte 在前，程式以 LE16 讀進來比較），字串以 `FFFF` 結束。讀音是 JIS X 0201 半形片假名（1 byte／字）。

| 項目 | 內容 |
|------|------|
| 字表 | `$06:8180`（檔案 0x30180）1113 個 SJIS 碼，`FFFF` 結尾。`$00:BE6B` 線性搜尋：找到 → glyph = 索引 + 0x6B；找不到 → 0x23。字串裡小於 0x48 的值直接當 glyph 號（`$00:BDCD`／`$00:BE08`） |
| 自訂碼 | 字表中 92 個 `EB9F–EC58`（JIS 沒有的人名／地名用字），對照在 `data/charset.txt`；其餘用 cp932 解（Python 的 `shift_jis` 解不了部分字，要用 `cp932`）。不確定：`EBF2` 衮、`EBF0` 䵋（黄＋有，依字形）、`EBA5` 未認出（青＋彡，人名「爰〓 ｴﾝｾｲ」） |
| glyph → tile | glyph g = tile 4g..4g+3（左上 右上 左下 右下），tile code = 0x8000 \| 4g |
| tile 位址 | `$00:A086` 依 tile code 的 bit 14–15 選來源：00 → `$25:8000`；01 → 地圖 chip（code − 0x4AC，`$26:8000` 或 `$7F:8000`）；10 → 字型；11 → `$7F:D1C8`。字型 tile t < 0x120：4bpp `$2C:8000 + 32 t`（檔案 0x160000）；t ≥ 0x120：1bpp `$2C:8000 + 0x2400 + 8 (t − 0x120)`（`$00:A47B`） |
| glyph 0x00–0x47 | 4bpp 按鈕字：0x00–0x1F 標籤（目視：人 令 兵 可 否 外 将 年 徳 采 政 交 軍 栄 武 治，0x10–0x1F 有幾個沒認出），0x20 空白按鈕、0x21 ▲、0x22 ▼、0x23 斜線（字表找不到時的替代字），0x24–0x47 是按下的樣子 |
| 半形字 | 字 h = tile 0x120 + 2h（上）、0x121 + 2h（下），8×16。順序：0–9、ｱ…ﾜ（10–53）、ｦ 54、ﾝ 55、ﾟ 56、ﾞ 57、ｬｭｮ 58–60、ｯ 61、ｧ–ｫ 62–66、/ 67、ｰ 68、空白 69 |
| 輸出 | 放字 `$00:A0CA`（A = tile code \| 旗標），所有文字都經過它，是驗證的好掛點；名字 `$00:CB70`（畫 `$7E:X` 起 3 個字） |

**已驗證**（`verify_text.py`，380 輪）：把字表 1113 字每 3 個一組寫進君主姓名、讀音用的 59 個半形（假名、ｰ、空白）每 7 個一組寫進讀音，點君主卡，`$00:A0CA` 收到的 tile code 10640 個全部等於 `Rom.text_codes`／`half_codes`；字型位址（`$00:A47B` 1bpp 在 `$00:A4AD` 時的 `$14–$16`、`$00:A086` 4bpp 在 RTS `$00:A106` 時）18240 個全部等於上表公式（含卡片先畫的數字 0–9 tile 0x120–0x133）。沒涵蓋：glyph 0x00–0x47（放在姓名裡不經過 `$00:A0CA`，0x00–0x0B 有出現，其餘沒有，原因未查）；讀音裡的數字與 / 不會轉換，顯示成 ｰ。

人工核對的例子：劉虞的君主卡掛 `$00:A0CA` 得到 81BC–81BF（劉 = 字表索引 4）、81B0（全形空白，索引 1）、8268（虞），讀音 81AA（空白）8182 ﾘ 8196 ｭ 8138 ｳ 8142 ｸ 8192 ﾞ 81AA 81AA，官職 8F84 幽 87C0 州 8ABC 牧 81B0；和上表的換算一致。卡片上的數字不是文字，是 OAM 數字 sprite（§4）。

## 4. 劇本（`$00:CA31`，A = 劇本 0–3）

從 `$08:8000`（檔案 0x40000）開始，每劇本 3 個串流，A 個劇本用 `$00:CA13` 跳過 3A 個，然後依序解到：

| 串流 | WRAM | 大小 | 劇本 1／2／3／4 的檔案偏移 |
|------|------|------|------|
| 人物 | `$7E:8018` | 600 × 35 = 21000 | 0x40000／0x44411／0x4886F／0x4CC50 |
| 勢力 | `$7E:D220` | 15 × 30 = 450 | 0x43B19／0x47F2A／0x4C352／0x50797 |
| 郡国 | `$7E:D3E2` | 126 × 32 = 4032 | 0x43C90／0x48035／0x4C411／0x50838 |

載入程式在 `$00:CA8D`（RTS）結束。**已驗證**（`verify_scenarios.py`）：4 劇本在 `$00:CA8D` dump `$7E:8018–$E3A1`，人物 21000、勢力 450、郡国 4032 bytes 全部和 `Rom.scenario_wram(k)` 相同。開始遊戲後人物 +14 會改（見 §4.1）。

人物欄位的驗證（`verify_persons.py`，4 劇本 × 600 人全部相符）：在 `$00:CA8D` 把人物 p 的 35 bytes 蓋到勢力 0 君主的紀錄，點君主卡，比對 `$00:A0CA` 的字碼（20 個數字 tile 之後是 姓名 3 字、讀音 8 半形、官職前 4 字）與 OAM 數字 sprite（16×16，tile 0xE4 + 2d（d ≤ 5）、0x100 + 2(d − 6)，空白 0x140；政 外 策 在 y 104 的 x 80／120／160，采 武 徳 在 y 128，年 在 (80,152)，郡国數 在 (160,152)）。

人物的 600 格每個劇本重新分配：同一編號在不同劇本可能是不同人（劇本 2–4 和劇本 1 的名字分別有 293／363／367 格不同），所以人物表是「劇本 × 編號」。

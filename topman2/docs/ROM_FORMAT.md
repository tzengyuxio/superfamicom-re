# SFC トップマネジメントII ROM 格式

ROM：`Top Management II (Japan)`，1.5 MB（0x180000）LoROM，無 copier header，SRAM 8 KB。CPU 位址寫成 `$BB:AAAA`，ROM 檔案偏移寫成 `0x…`（LoROM：`(bank & 0x7F) × 0x8000 + (addr & 0x7FFF)`）。

## 1. 硬體與引擎

- 程式是 C 編譯的原生 65816（和エアーマネージメントII 同一套編譯器風格：引數用 `PEA` 推堆疊、`$00`／`$04`／`$08` 當暫存、`JSL $01:F0D3` 之類的比較／乘除 helper），放在 bank `$00`–`$1A`（0x00000–0xD7FFF）；不是 KOEI p-code。
- 資源放在 249 個具名檔（0xD8000–0x144C3D），其中 231 個是 KOEI LZ（共用 `tools/koei_lz.py`，解壓表在 0x4D79，沒有指標表）；其餘是調色盤等原始資料。
- NMI 向量 `$8400`（`tools/replay.py` 自動算）。開場動畫不能跳過，約 1300 幀後才進標題。
- 開機約 649 幀時用 MVN 把 bank `$01` 的 .data 初值複製進 WRAM：`$01:BCF8`(360)→`$3FE6`、`$C058`(168)→`$414E`、`$C1A8`(168)→`$41F6`、`$C3F4`(86)→`$42F2`、`$C512`(125)→`$4370`、`$C69D`(32)×3→`$48E2`／`$4902`／`$4922`、`$C6BD`(30)×3→`$4C54`／`$4C72`／`$4C90`（意義未解，§9）。同一段開機程式也會清掉 `$7E:E000` 一帶，驗證腳本要從 Lua 端帶參數（§8）。

## 2. 檔案表（ROM `0x6000`）

16 bytes 一筆，`name[0] = 0` 結束，共 249 筆：

| 偏移 | 大小 | 內容 |
|------|------|------|
| 0 | 8 | 檔名（ASCII，0 補齊） |
| 8 | 2 | CPU 位址 LE16 |
| 10 | 2 | bank LE16 |
| 12 | 4 | 大小 LE32 |

注意位址在 bank 前面，和エアーマネージメントII（bank、位址）相反。清單見 `output/files.csv`。和本文有關的檔：

| 檔 | 內容 |
|----|------|
| `FACEPAL` | 頭像調色盤（16 色，原始資料） |
| `KAICHO` `SHACHO` `HISHO` `SHABU` `JINBU` `KEIBU` `BAIBU` `KOUBU` `KAIBU` `EIGBU` `SEIBU` | 頭像（LZ，§6） |
| `JAPANL` | 日本地形圖（LZ 7392：調色盤 32＋tilemap 28 × 24＋188 tile） |
| `JAPANS` | 都道府縣示意圖（LZ 13496：調色盤 32＋tilemap 18 × 22＋396 tile） |
| `FLUCT` `FLUCT2` | 劇本頁的景氣曲線（LZ 8192，預先畫好的 tile） |

## 3. 文字

- 字串是 Shift-JIS，以 0 結尾，可直接用 cp932 解碼（`~` 等字元照 ROM 原樣保留，畫面上的字形沒有另外比對）。
- 字串表是 3-byte 指標（addr LE16＋bank）。
- 文字繪製函式 `$01:9392`：進入時 `S+4` 視窗、`S+6` 字串長指標（3 bytes）。`$01:8009` 是 sprintf 類（新聞的 `%d%%` 由它代入）。

## 4. bank `$01` 的表

| 位址 | 格式 | 內容 |
|------|------|------|
| `$D3CF` | 47 指標 | 都道府縣名（北海道..沖縄，JIS 順序；番號＝索引＋1） |
| `$C9CB` | 5 × 47 LE16 | 各縣人口（萬人）。5 筆對應開始年 <1980、<1985、<1990、<1995、其他；開局時 `$07:A403` 依 `$2812` 選一筆複製到 WRAM `$4417`（94 bytes） |
| `$CBA1` | 6 LE16 | 10000 7500 5000 5000 7500 10000（未解） |
| `$CBAD` | 47 × (x, y) LE16 | JAPANL 畫面上的縣位置：地圖畫在 BG cell (2, 3)，即畫面像素 (16, 24)；座標 ＋8 落在該縣的主要都市附近（由圖比對推得，讀取它的程式未追） |
| `$CC69` | 47 × (x, y) LE16 | 約等於該縣 JAPANS 填色段的重心 ＋(12, 19)，應是某個畫面上的位置（未解）。31 鳥取／32 島根的兩筆互換了（ROM 本身如此） |
| `$CD25` | 47 筆變長 | JAPANS 上各縣的填色段：`count`(1)、`vertical`(1)、`count × (x, y, len)`；`vertical = 0` 為橫段、1 為縱段。47 筆剛好結束在 `$D36B`（頭像檔名字串）。`$13:EAEE` 用它替縣上色 |
| `$C661` | 15 × 2 LE16 | PRESENT MODE 開局的本社候補對（1 起算縣番號，§5.2） |
| `$D54F` | 3 指標 | DTOP／LTOP／NOTE |
| `$D567` | 3 指標 | DESKTOP／LAPTOP／NOTE |
| `$D584` | 3 指標 | デスクトップ／ラップトップ／ノ－トブック |
| `$D5E9` | 9 指標 | 6 個 PRESENT 劇本名＋FREE 的ショ－ト／ミドル／ロング |
| `$D6C1` | 5 指標 | 難度 BEGINNER／EASY／NORMAL／HARD／PRO |
| `$D6EE` | 4 指標 | 股票的產業：電子／鉄鋼／自動車／サービス |
| `$D7EF` | 26 指標 | 新聞標題（含 `%d%%`） |
| `$D36B`.. | 字串 | 頭像檔名 SHACHO、HISHO、KAICHO…（§6） |

其他指令說明表（只列位置）：`$02:89DD`、`$02:8AC5`（BEGINNER 7＋7）、`$02:F876`（10）、`$02:F9C6`（14）。

## 5. 劇本與開局狀態

### 5.1 劇本

| WRAM | 內容 |
|------|------|
| `$280C` | 劇本號（0–5 PRESENT，6–8 FREE 的短／中／長） |
| `$2810` | 結束年 |
| `$2812` | 開始年；開局（`$07:92AF`）會先減 1，進入遊戲後讀到的是開始年 − 1 |
| `$2814` | 4（月？未確認） |
| `$2816` | 劇本號 byte |
| `$4417` | 47 × LE16 人口（`$C9CB` 的一筆） |

- PRESENT 的年份是 `$06:A4E3` 起的 switch 立即值（`LDA #start; STA $2812; LDA #end; STA $2810`）：平成景気 1987–1991、半導体景気~円高不況 1982–1986、第２次オイルショック 1978–1982、オイルショックからの脱出 1981–1990、バブル経済の崩壊 1986–1995、過去から未来へ 1978–1997。
- 劇本頁說明文字：`$06:9973` 起每 31 bytes 一組 `PEA bank; PEA lo`（bank 先推），共 8 組：6 個劇本、FREE 短／中、FREE 長。
- FREE MODE：短、中的開始年自選（`$06:A3FB`：1978 ＋ 年份頁游標位置換算，R 鍵一次 +1 年），結束年 = 開始年 ＋4（短）／＋9（中）；長固定 1978–1997。

### 5.2 公司

WRAM `$2820` 起 3 × 21 bytes：

| 偏移 | 內容 |
|------|------|
| 0 | MAN 旗標 LE16（玩家操作） |
| 2 | 本社縣番號 LE16（1 起算） |
| 4 | 開局後寫入同本社的值 LE16 |
| 6 | 公司名（Shift-JIS，15 bytes） |

- 預設名在 `$06:F2A2`／`$06:F2AF`／`$06:F2BC`（ＮＥパソコン、ＦＴパソコン、ＳＳパソコン），由 `$06:8A1A` 複製。
- `$3638 + 6c`：48-bit 據點遮罩（bit p＝第 p 縣，0 起算，含本社）。
- PRESENT MODE 開機時 `$06:8AE1(c)` 用亂數 `$01:F1AD` 取 r1 = 0..14、r2 = 0..1：據點 = `$C661` 第 r1 對的兩縣，本社 = 其中第 r2 個。亂數是決定性的，從開機直接玩是 NE 大阪（＋東京）、FT 神奈川（＋大阪）、SS 大阪（＋千葉）。
- FREE MODE 另有「本社、支社地區を変更しますか?」「会社名を変更しますか?」兩頁可改。

## 6. 頭像

- 11 個 LZ 檔，每檔是 n 個 816-byte frame：24 個 tilemap word（4 × 6，調色盤 2，tile 號寫死在檔裡）＋24 個 4bpp tile。
- 調色盤：`FACEPAL` 一組 16 色，載到 CGRAM 第 2 列。
- 共用繪製函式 `$01:B0D8(name, 1, 1, x, y, 4, 6, frame, slot)`：解壓檔案、tile 寫到 VRAM（第一個 tile 號 × 32）、tilemap 寫到 BG `$E800`（32 寬）的 (x, y)。引數在 `S+4` 名稱指標、`S+10` x、`S+12` y、`S+18` frame、`S+20` slot。
- bank `$05` 的包裝決定 frame：

| 檔 | 包裝 | frame | 角色 |
|----|------|-------|------|
| KAICHO | `$05:879E` | 3 人 × 4 表情 | 会長 |
| SHACHO | `$05:8715` | 公司號（slot 0x18／0x30／0x48） | 社長（3 社各 1） |
| HISHO | `$05:8768` | 3 人 × 3 表情 | 秘書（NEW GAME 後第一個畫的是 HISHO frame 1 at (5, 2)） |
| SHABU | `$05:87CD` | 3 × 3 | 部長（哪一部未定） |
| JINBU | `$05:8803` | 3 × 3 | 人事部長（由檔名推斷） |
| KEIBU | `$05:8839` | 3 × 3 | 経理部長（推斷；股票畫面） |
| BAIBU | `$05:886F` | 3 × 3 | 部長（推測購買部，未定） |
| KOUBU | `$05:88A5` | 3 × 3 | 広告部長（宣伝員） |
| KAIBU | `$05:88DB` | 3 × 3 | 開発部長（Mesen 觀察） |
| EIGBU | `$05:8911` | 3 × 3 | 営業部長（Mesen 觀察） |
| SEIBU | `$05:8947` | 3 × 3 | 製造部長（Mesen 觀察） |

部長檔的人＝公司。表情 0 笑、1 普通（遊戲預設）、2 困擾。共 96 frame（会長 12、社長 3、秘書 9、部長 72）。BEGINNER 只有広告／開発／営業／製造 4 部門。PC-98 版（kaodata `topman2-pc98`）是社長 3、秘書 9、部長 72、会長・株主 48（64 × 64）。

## 7. 地圖

- **JAPANL**：調色盤 32 bytes（載到 CGRAM 第 3 列）＋tilemap 28 × 24 word＋188 個 4bpp tile（tile 號 0xA0 起，VRAM 0x1400）。FREE MODE 改本社／支社時顯示，tilemap 畫在 BG `$E800` 的 cell (2, 3)，部分列被視窗蓋住。
- **JAPANS**：調色盤＋tilemap 18 × 22＋396 tile（tile 0x3C 起），都道府縣的白色示意圖；`$13:EA63` 載入（呼叫者 `$12:BB31`、`$13:E962`），再用 `$01:CD25` 的填色段替各縣上色（`$13:EAEE`）。在遊戲中的哪個畫面出現沒有找到，未在 Mesen 驗證（圖檔格式和 JAPANL 相同）。
- 沒有戰鬥，沒有戰術地圖。

## 8. 操作序列（驗證用，幀數從開機算）

- 標題：`w1300 start:10 w200`；NEW GAME `a:10`（秘書頭像約在第 1598 幀畫）；PRESENT MODE 的劇本選單：`a:10 w200 a:10 w300`（約第 2100 幀）。
- 劇本選單按下的時機不對會選到別的劇本，驗證一律讀 WRAM `$280C` 確認。
- PRESENT 開局：選劇本後 `a:10 w300` × 9。FREE 開局：`down:3 w60 a:10 w300`（FREE）、長度、年份頁（R 鍵 +1 年；方向鍵短按無效）、再 `a:10 w300` × 16。
- 開機會清 `$7E:E000` 一帶，在 savestate 時寫進 WRAM 的參數到 `$06:8AE1` 執行時已被清掉；驗證腳本在 `EXTRA_RESET` 把參數讀進 Lua 表再給 hook 用。
- 換 hook 引數的 Lua 要比記錄用的 hook 先註冊，記錄到的才是換過的值。

## 9. 未解

- 開機 MVN 複製的 .data 表（`$01:BCF8` 起 7 段）、`$CBA1` 的 6 個值的意義。
- `$CC69` 座標用在哪個畫面；`$CBAD` 讀取它的程式。
- JAPANS 在遊戲中的畫面（未在 Mesen 驗證）；`KMAP`、`PREMAP`～`PREMAP4`、`PREFECT` 的用途。
- 景氣曲線（FLUCT／FLUCT2 是預畫 tile）背後的數列、市場與需求模擬、事業計畫、股票、事件（`MEVENT*`）。
- `$2814` 的意義（推測是起始月）。
- 部長檔 SHABU、BAIBU 對應的部門；JINBU、KEIBU 是由檔名推斷。
- 產品（DESKTOP／LAPTOP／NOTE）的能力值與價格表。
